Tulis

A writing app for playing with your words. Keep alternates inline, ghost passages to judge a paragraph without them, stash text in an Overflow scratchpad, and ask an AI for alternatives or cuts — never rewrites.

In this guide Ctrl means Cmd on macOS. Press Ctrl+? in the app at any time for a searchable cheat sheet.

Getting started

Tulis is built with Rust and GPUI. From the repository root:

cargo run --release -p tulis -- path/to/essay.md

The window shows your text in a centered 640px column. The header shows word and character counts and the file name appears in the window title, with a • when there are unsaved changes. The footer has Save, Open, Share (X and LinkedIn), LAB and XYZ (Overflow) buttons.

Basic editing works as you expect: arrows, Home/End, PageUp/PageDown, mouse selection, double-click for a word, triple-click for a paragraph, copy/cut/paste, and IME input. Typing undoes in chunks. If the first paragraph starts with # it is shown as a bold title.

Themes: Ctrl+K then T cycles Midnight, Paper, Sepia and Black for the session. Set a permanent one in the config.

Files & the sidecar

Your document is plain Markdown (essay.md). Everything Tulis adds — alternates, ghosts and the Overflow text — lives in a sidecar file next to it, essay.md.tulis.json. The .md stays clean: ghosted text is left out of it, and only the alternate you are showing is written.

KeyAction
Ctrl+SSave
Ctrl+Shift+SSave as
Ctrl+OOpen
Ctrl+NNew
Ctrl+QQuit

New, Open, Quit and closing the window ask before discarding unsaved changes.

If you edit the Markdown in another editor, Tulis keeps the metadata of every paragraph that still matches and tells you how many paragraphs lost theirs.

Alternates & paragraph versions

An alternate is another way of saying a word, phrase or sentence, stored inline at the same spot. Text with alternates gets a dotted underline (in the accent colour when an AI wrote it). A paragraph with versions gets a bar to the left of the column with a ⋮ handle; click the handle to open the sidebar on its Paragraph tab.

KeyAction
Alt+↑ / Alt+↓Cycle through the alternates or versions. A faint box marks the group until the cursor leaves it.
Ctrl+EnterAccept: keep only the one currently shown.
Ctrl+Shift+BackspaceDelete the one currently shown.
Ctrl+.Show or hide all alternate and version markers.

The header shows an alt i/n badge while your cursor is in a group.

The Alternatives sidebar

Select some text (or just put the cursor in a word) and press Ctrl+Shift+A or Ctrl+D. A sidebar opens on the left, and the page dims around its target.

Tabs

Word (or Selection when you have a selection), Sentence and Paragraph. Each tab lists the options for that level. A ● marks the one shown on the page, · the others and ✦ AI-written ones. Long options clip at three lines.

Working in it

  • ↑/↓ or j/k preview an option on the page.
  • Enter keeps the highlighted option.
  • Delete or dd removes it (never the last one).
  • i or o focuses “type another way to say it…”; type and press Enter to add and show it.
  • Ctrl+Z / Ctrl+Shift+Z undo and redo; closing the sidebar leaves the whole preview session as a single undo step.
  • Esc closes it and keeps what is shown. Esc on the page also closes it when there is nothing else to cancel.

Adding a sentence-level option over a word that already has alternates merges the inner ones, with a toast “Inner alternates merged — Ctrl+Z to restore”. Deleting the target paragraph, or typing inside it, closes the sidebar.

Ghosts

Ghosting fades a selection or paragraph to about 10% so you can judge how the writing reads without it, without deleting anything. Ghosted text is kept in the sidecar and left out of the saved .md and the Markdown preview.

KeyAction
Ctrl+/ or Ctrl+GGhost the selection or paragraph; press again on ghosted text to revive it.
Ctrl+Shift+MMarkdown preview (without ghosts). Esc returns.

Overflow scratchpad

Overflow is a free-text scratchpad for lines you cut but don't want to lose. Blocks are separated by blank lines. It saves in the sidecar and has its own undo, so page undo never touches it.

Putting text in

Ctrl+Shift+X (or Ctrl+Shift+O) stashes the selection or paragraph. It is appended after a blank line, a “Stashed to Overflow” toast appears, and the panel stays closed. You can also stash from the right-click menu.

The panel

Ctrl+\ (or the XYZ button) shows or hides the 260px panel on the right. Ctrl+Shift+\ moves focus between page and scratchpad, opening it if needed; Esc in the scratchpad returns to the page.

Taking text back out

  • Ctrl+Enter in the scratchpad moves its selection (or the block at the cursor) to the page cursor.
  • Ctrl+Shift+Enter copies it and keeps focus where it is.
  • Or hover a block, grab its ⠿ grip and drag it onto the page. Hold Ctrl to copy instead of move.

A single page Ctrl+Z puts a moved block back.

AI alternatives

The AI only suggests; it never rewrites your text. Press Ctrl+Shift+G (or Ctrl+J) to request alternatives for the selection, or for the paragraph (as versions) when nothing is selected. With the sidebar open, the key asks for the sidebar's target instead, as does the sidebar's ✦ Ask AI row. A cursor inside a Lab mark asks for alternatives to that mark.

The results arrive as ordinary alternates, so everything in Alternates applies. Without an API key you get a “missing key” notice and nothing is sent. Configure the provider in Configuration.

The Lab

The Lab reviews your writing. Open it with Ctrl+L or the LAB button; it appears above the button with focus inside. It works on the selection's paragraphs, or the whole document if nothing is selected. Ctrl+Shift+T scopes it to the cursor's paragraph and Ctrl+Shift+Alt+T to the whole document.

Move with the arrows or j/k, run with Enter. Click “what each idea does” to see a one-line description under each check. Esc closes the Lab and stops a run in progress (“Lab stopped”; no further requests are sent).

Trim levels

A trim level fades the words it would cut so you can see the shorter version in place.

LevelCut target
Original0%
Slight trimabout 10%
Tighten moreabout 20%
Even sharperabout 30%
Cut in halfabout 50%

The bar reads “<Level> N → M words · −P%” with “Faded words would go. Click one to keep it.” Choosing a level again is instant (cached).

  • Keep a cut: click a faded passage (or press Enter in it). Click again to fade it again.
  • Move between cuts: Tab / Shift+Tab.
  • Make the cuts: ghosts every faded passage (“Cut N passages”). One Ctrl+Z restores them all.
  • Walk through: selects each cut in turn (“Cut i of n”). y/Enter cuts, n/Backspace keeps, Esc stops.
  • Done (or Esc) clears the preview with no change.
Cuts are ghosts, not deletions: you can revive any of them later with Ctrl+/.

Configuration

Tulis reads ~/.config/tulis/config.toml (on macOS, ~/Library/Application Support/tulis/config.toml).

[editor]
vim_mode = false
font_family = "IBM Plex Mono"   # falls back to IBM Plex Mono, JetBrains Mono, then the platform mono font
font_size = 18
theme = "midnight"              # midnight | paper | sepia | black
long_sentence_words = 30        # the Lab's "Mark sentences that run long" check

[ai]
provider = "openai"                         # any OpenAI-compatible endpoint, or "anthropic"
model = "openrouter/auto"                   # any OpenRouter model id
api_key_env = "OPENROUTER_API_KEY"          # the key is read from this environment variable
base_url = "https://openrouter.ai/api/v1"   # e.g. "http://localhost:11434/v1" for Ollama
num_alternates = 3

Using Anthropic directly

[ai]
provider = "anthropic"
model = "claude-haiku-5-5"
api_key_env = "ANTHROPIC_API_KEY"
base_url = ""

Using a local model

Keep provider = "openai", set base_url = "http://localhost:11434/v1" for Ollama and point model at a model you have pulled.

The API key is never stored in the config: export it in your shell (for example export OPENROUTER_API_KEY=…) before launching Tulis. An unknown theme shows a toast and falls back to Midnight.

Known limits

  • The Sentence tab ends sentences at ., ! or ? followed by a space or the end of the paragraph.
  • A sentence ending in an abbreviation such as etc. or e.g. runs on into the next one.
  • Other dotted abbreviations end a sentence: “The U.S. economy” splits after “U.S.”.
  • CJK 。 does not end a sentence.
