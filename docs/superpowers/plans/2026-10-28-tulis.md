# Tulis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tulis, a Rust + GPUI desktop writing app with inline alternates, ghosting, an overflow panel, AI alternates/trim, Markdown+sidecar storage and an optional vim mode.

**Architecture:** A Cargo workspace with two crates. `tulis-core` holds all logic with no GPUI dependency: the document model and its edit operations, undo history, storage, config, motions, the vim state machine and the AI providers. It is developed test-first. `tulis` is the GPUI app: a custom text `Element` that renders paragraphs from the core model, an `Editor` entity that implements `EntityInputHandler` and the actions, and a `Workspace` root view with the overflow panel, status bar and file operations.

**Tech Stack:** Rust 1.98 (edition 2024), `gpui` 0.2.2, `serde`/`serde_json`, `toml`, `chrono`, `thiserror`, `sha2`+`hex`, `dirs`, `ureq` 3 (blocking HTTP), `unicode-segmentation`, `tempfile` (tests).

**Spec:** `docs/superpowers/specs/2026-10-28-tulis-design.md`. Read it before starting any task.

## Global Constraints

- Version control is **jj** (`jj describe -m … && jj new` to commit). Never use `git commit` directly.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `tulis-core` must not depend on `gpui`.
- Positions are **byte offsets** into a paragraph's *rendered* text (ghosts included) and always lie on char boundaries. Only the GPUI input handler converts to and from UTF-16.
- Paragraph text never contains `\n`. Paragraph breaks are boundaries between `Paragraph`s.
- `gpui = "0.2.2"` needs the vendored `xattr` patch (Task 11). Without it, `xattr 0.2.3` fails to compile against current `libc` on Linux (`ENOATTR` was removed).
- Anthropic requests send `anthropic-version: 2026-10-21` and no `temperature`/`top_p`/`top_k` (that version rejects them).
- Default AI provider: OpenAI-compatible via OpenRouter: `provider = "openai"`, `base_url = "https://openrouter.ai/api/v1"`, `model = "openrouter/auto"`, `api_key_env = "OPENROUTER_API_KEY"`. All of these can be changed in config. `provider = "anthropic"` stays supported: it uses `base_url` if set, or `https://api.anthropic.com` if `base_url = ""`.
- API keys come only from the env var named by `ai.api_key_env`. Never read them from or write them to files.
- Run `cargo test -p tulis-core` after every core task and `cargo test --workspace` after every app task. Both must pass before committing.
- Code style: idiomatic Rust, `cargo fmt` before each commit, no `unwrap()` on user/IO data outside tests.
- GPUI API reference: `~/.cargo/registry/src/*/gpui-0.2.2/examples/input.rs` (text input, `EntityInputHandler`, custom `Element`) and `src/text_system/line_layout.rs` (`WrappedLineLayout`). The GPUI code in this plan was written against 0.2.2's signatures. If one doesn't compile, check those files before changing behavior.

//! The document model: paragraphs made of segments, with alternates and ghosts.

use std::ops::Range;

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
pub struct ParaId(pub u64);

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct OverflowId(pub u64);

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum AiKind {
    Rewrite,
    Trim,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum Source {
    Human,
    Ai { provider: String, model: String, kind: AiKind },
}

impl Source {
    pub fn is_ai(&self) -> bool {
        matches!(self, Source::Ai { .. })
    }
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct AltOption {
    pub text: String,
    pub source: Source,
}

impl AltOption {
    pub fn human(text: impl Into<String>) -> Self {
        Self { text: text.into(), source: Source::Human }
    }
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum SegKind {
    Plain(String),
    Alt { options: Vec<AltOption>, active: usize },
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Segment {
    pub kind: SegKind,
    pub ghost: bool,
}

impl Segment {
    pub fn plain(text: impl Into<String>, ghost: bool) -> Self {
        Self { kind: SegKind::Plain(text.into()), ghost }
    }

    pub fn alt(options: Vec<AltOption>, active: usize, ghost: bool) -> Self {
        Self { kind: SegKind::Alt { options, active }, ghost }
    }

    /// The visible text: the plain string, or the active option's text.
    pub fn text(&self) -> &str {
        match &self.kind {
            SegKind::Plain(text) => text,
            SegKind::Alt { options, active } => &options[*active].text,
        }
    }

    pub fn text_mut(&mut self) -> &mut String {
        match &mut self.kind {
            SegKind::Plain(text) => text,
            SegKind::Alt { options, active } => &mut options[*active].text,
        }
    }

    pub fn is_alt(&self) -> bool {
        matches!(self.kind, SegKind::Alt { .. })
    }

    /// True when this is an alternate whose active option came from an AI.
    pub fn active_is_ai(&self) -> bool {
        match &self.kind {
            SegKind::Alt { options, active } => options[*active].source.is_ai(),
            SegKind::Plain(_) => false,
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct ParaVersion {
    pub segments: Vec<Segment>,
    pub source: Source,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Paragraph {
    pub id: ParaId,
    pub versions: Vec<ParaVersion>,
    pub active: usize,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct AltMark {
    pub ai: bool,
}

/// A run of a paragraph's rendered text with uniform styling.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Span {
    pub range: Range<usize>,
    pub ghost: bool,
    pub alt: Option<AltMark>,
}

impl Paragraph {
    pub fn new(id: ParaId, text: impl Into<String>) -> Self {
        let mut segments = vec![Segment::plain(text, false)];
        normalize_segments(&mut segments);
        Self { id, versions: vec![ParaVersion { segments, source: Source::Human }], active: 0 }
    }

    pub fn segments(&self) -> &[Segment] {
        &self.versions[self.active].segments
    }

    pub fn segments_mut(&mut self) -> &mut Vec<Segment> {
        &mut self.versions[self.active].segments
    }

    /// Rendered text of the active version, ghosts included.
    pub fn text(&self) -> String {
        self.segments().iter().map(Segment::text).collect()
    }

    /// Rendered text without ghosted segments.
    pub fn export_text(&self) -> String {
        self.segments().iter().filter(|s| !s.ghost).map(Segment::text).collect()
    }

    pub fn len(&self) -> usize {
        self.segments().iter().map(|s| s.text().len()).sum()
    }

    pub fn is_empty(&self) -> bool {
        self.len() == 0
    }

    /// Byte range of each segment of the active version within the rendered text.
    pub fn segment_ranges(&self) -> Vec<Range<usize>> {
        let mut start = 0;
        self.segments()
            .iter()
            .map(|s| {
                let range = start..start + s.text().len();
                start = range.end;
                range
            })
            .collect()
    }

    pub fn spans(&self) -> Vec<Span> {
        self.segments()
            .iter()
            .zip(self.segment_ranges())
            .filter(|(_, range)| !range.is_empty())
            .map(|(seg, range)| Span {
                range,
                ghost: seg.ghost,
                alt: seg.is_alt().then(|| AltMark { ai: seg.active_is_ai() }),
            })
            .collect()
    }

    /// Whether the paragraph carries anything that plain Markdown would lose.
    pub fn has_metadata(&self) -> bool {
        self.versions.len() > 1
            || self.versions.iter().any(|v| v.segments.iter().any(|s| s.ghost || s.is_alt()))
    }

    pub(crate) fn keep_only_active_version(&mut self) {
        let version = self.versions[self.active].clone();
        self.versions = vec![version];
        self.active = 0;
    }
}

/// Drop empty plain segments and merge adjacent plain segments with the same ghost flag.
/// An empty list becomes a single empty plain segment.
pub fn normalize_segments(segments: &mut Vec<Segment>) {
    let mut out: Vec<Segment> = Vec::with_capacity(segments.len());
    for seg in segments.drain(..) {
        if let SegKind::Plain(text) = &seg.kind {
            if text.is_empty() {
                continue;
            }
            if let Some(Segment { kind: SegKind::Plain(prev), ghost }) = out.last_mut() {
                if *ghost == seg.ghost {
                    prev.push_str(text);
                    continue;
                }
            }
        }
        out.push(seg);
    }
    if out.is_empty() {
        out.push(Segment::plain("", false));
    }
    *segments = out;
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct OverflowItem {
    pub id: OverflowId,
    pub text: String,
    pub created_at: DateTime<Utc>,
    pub from_paragraph: Option<ParaId>,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Document {
    pub paragraphs: Vec<Paragraph>,
    pub overflow: Vec<OverflowItem>,
    next_id: u64,
}

impl Default for Document {
    fn default() -> Self {
        Self::new()
    }
}

impl Document {
    pub fn new() -> Self {
        Self::from_texts::<&str>(&[])
    }

    pub fn from_texts<S: AsRef<str>>(texts: &[S]) -> Self {
        let mut doc = Self { paragraphs: Vec::new(), overflow: Vec::new(), next_id: 1 };
        for text in texts {
            let p = doc.new_paragraph(text.as_ref());
            doc.paragraphs.push(p);
        }
        if doc.paragraphs.is_empty() {
            let p = doc.new_paragraph("");
            doc.paragraphs.push(p);
        }
        doc
    }

    pub fn fresh_id(&mut self) -> u64 {
        let id = self.next_id;
        self.next_id += 1;
        id
    }

    /// Creates (but does not insert) a paragraph with a fresh id.
    pub fn new_paragraph(&mut self, text: impl Into<String>) -> Paragraph {
        Paragraph::new(ParaId(self.fresh_id()), text)
    }

    pub fn para_index(&self, id: ParaId) -> Option<usize> {
        self.paragraphs.iter().position(|p| p.id == id)
    }

    /// Export text of every paragraph whose export text is non-empty.
    pub fn export_paragraphs(&self) -> Vec<String> {
        self.paragraphs.iter().map(Paragraph::export_text).filter(|t| !t.is_empty()).collect()
    }

    pub fn word_count(&self) -> usize {
        self.paragraphs.iter().map(|p| p.export_text().split_whitespace().count()).sum()
    }
}

Rules (from the spec): typing strictly inside an alternate or a ghost goes into it. Typing at an edge goes into a touching non-ghost plain segment, or else into a new plain segment. Enter at offset 0 or at the end inserts an empty paragraph and keeps the original paragraph's id and versions. A split in the middle keeps only the active version and collapses an alternate the split falls inside. Deleting across paragraphs keeps only each side's active version.

//! Positions and selections in a document.

use std::ops::Range;

/// A cursor position: paragraph index and byte offset into its rendered text.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct DocPos {
    pub para: usize,
    pub offset: usize,
}

impl DocPos {
    pub fn new(para: usize, offset: usize) -> Self {
        Self { para, offset }
    }
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct Selection {
    pub anchor: DocPos,
    pub head: DocPos,
}

impl Selection {
    pub fn caret(pos: DocPos) -> Self {
        Self { anchor: pos, head: pos }
    }

    pub fn is_empty(&self) -> bool {
        self.anchor == self.head
    }

    /// The selected range with its ends ordered.
    pub fn range(&self) -> Range<DocPos> {
        if self.reversed() { self.head..self.anchor } else { self.anchor..self.head }
    }

    pub fn reversed(&self) -> bool {
        self.head < self.anchor
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn positions_order_by_paragraph_then_offset() {
        assert!(DocPos::new(0, 9) < DocPos::new(1, 0));
        assert!(DocPos::new(1, 2) < DocPos::new(1, 3));
    }

    #[test]
    fn range_is_ordered_for_reversed_selection() {
        let sel = Selection { anchor: DocPos::new(1, 4), head: DocPos::new(0, 2) };
        assert!(sel.reversed());
        assert_eq!(sel.range(), DocPos::new(0, 2)..DocPos::new(1, 4));

//! Text editing on the document: insert, delete, split and join.

use std::ops::Range;

use crate::model::{Document, Paragraph, Segment, normalize_segments};
use crate::pos::DocPos;

enum InsertAt {
    Into { seg: usize, at: usize },
    NewPlainBefore(usize),
}

impl Paragraph {
    fn insertion_point(&self, offset: usize) -> InsertAt {
        let ranges = self.segment_ranges();
        let segs = self.segments();
        // Strictly inside an alternate or a ghost: edit it.
        for (i, r) in ranges.iter().enumerate() {
            if r.start < offset && offset < r.end && (segs[i].is_alt() || segs[i].ghost) {
                return InsertAt::Into { seg: i, at: offset - r.start };
            }
        }
        // Touching a normal plain segment (inside or at an edge).
        for (i, r) in ranges.iter().enumerate() {
            if !segs[i].is_alt() && !segs[i].ghost && r.start <= offset && offset <= r.end {
                return InsertAt::Into { seg: i, at: offset - r.start };
            }
        }
        // Only alternates or ghosts touch this offset: start a new plain segment here.
        let before = ranges
            .iter()
            .position(|r| r.start >= offset && !r.is_empty())
            .unwrap_or(ranges.len());
        InsertAt::NewPlainBefore(before)
    }

    /// Insert text that contains no newline at `offset`.
    pub(crate) fn insert_text(&mut self, offset: usize, text: &str) {
        debug_assert!(!text.contains('\n'));
        if text.is_empty() {
            return;
        }
        match self.insertion_point(offset) {
            InsertAt::Into { seg, at } => self.segments_mut()[seg].text_mut().insert_str(at, text),
            InsertAt::NewPlainBefore(ix) => self.segments_mut().insert(ix, Segment::plain(text, false)),
        }
        normalize_segments(self.segments_mut());
    }

    /// Delete a byte range of the rendered text. Alternates whose active text becomes empty are removed.
    pub(crate) fn delete_text(&mut self, range: Range<usize>) {
        if range.is_empty() {
            return;
        }
        let ranges = self.segment_ranges();
        let segs = self.segments_mut();
        for (i, r) in ranges.iter().enumerate() {
            let start = range.start.max(r.start);
            let end = range.end.min(r.end);
            if start < end {
                segs[i].text_mut().replace_range(start - r.start..end - r.start, "");
            }
        }
        segs.retain(|s| !(s.is_alt() && s.text().is_empty()));
        normalize_segments(segs);
    }

    /// Make sure a segment boundary exists at `offset`. A segment strictly containing it is split;
    /// an alternate strictly containing it is collapsed to its active text first.
    pub(crate) fn split_segments_at(&mut self, offset: usize) {
        let ranges = self.segment_ranges();
        if let Some(i) = ranges.iter().position(|r| r.start < offset && offset < r.end) {
            let start = ranges[i].start;
            let segs = self.segments_mut();
            let ghost = segs[i].ghost;
            let text = segs[i].text().to_string();
            let (left, right) = text.split_at(offset - start);
            segs.splice(i..=i, [Segment::plain(left, ghost), Segment::plain(right, ghost)]);
        }
    }
}

impl Document {
    pub fn end_pos(&self) -> DocPos {
        let last = self.paragraphs.len() - 1;
        DocPos::new(last, self.paragraphs[last].len())
    }

    /// Clamp to an existing paragraph and a char boundary at or before the offset.
    pub fn clamp(&self, pos: DocPos) -> DocPos {
        let para = pos.para.min(self.paragraphs.len() - 1);
        let text = self.paragraphs[para].text();
        let mut offset = pos.offset.min(text.len());
        while !text.is_char_boundary(offset) {
            offset -= 1;
        }
        DocPos::new(para, offset)
    }

    /// Insert text at `pos` (newlines split paragraphs). Returns the position after the text.
    pub fn insert(&mut self, pos: DocPos, text: &str) -> DocPos {
        let text = text.replace("\r\n", "\n").replace('\r', "\n");
        let mut lines = text.split('\n');
        let first = lines.next().unwrap_or("");
        let rest: Vec<&str> = lines.collect();
        if rest.is_empty() {
            self.paragraphs[pos.para].insert_text(pos.offset, first);
            return DocPos::new(pos.para, pos.offset + first.len());
        }
        let mut cur = self.split_paragraph(pos);
        let left = cur.para - 1;
        let left_len = self.paragraphs[left].len();
        self.paragraphs[left].insert_text(left_len, first);
        let (last, middle) = rest.split_last().expect("rest is non-empty");
        for line in middle {
            let p = self.new_paragraph(*line);
            self.paragraphs.insert(cur.para, p);
            cur.para += 1;
        }
        self.paragraphs[cur.para].insert_text(0, last);
        DocPos::new(cur.para, last.len())
    }

    /// Split the paragraph at `pos`. Returns the start of the second paragraph.
    pub fn split_paragraph(&mut self, pos: DocPos) -> DocPos {
        let len = self.paragraphs[pos.para].len();
        if pos.offset == 0 && len > 0 {
            let p = self.new_paragraph("");
            self.paragraphs.insert(pos.para, p);
            return DocPos::new(pos.para + 1, 0);
        }
        if pos.offset >= len {
            let p = self.new_paragraph("");
            self.paragraphs.insert(pos.para + 1, p);
            return DocPos::new(pos.para + 1, 0);
        }
        let right = {
            let para = &mut self.paragraphs[pos.para];
            para.keep_only_active_version();
            para.split_segments_at(pos.offset);
            let ix = para
                .segment_ranges()
                .iter()
                .position(|r| r.start >= pos.offset)
                .expect("a segment starts at the split offset");
            let right = para.segments_mut().split_off(ix);
            normalize_segments(para.segments_mut());
            right
        };
        let mut new_para = self.new_paragraph("");
        *new_para.segments_mut() = right;
        normalize_segments(new_para.segments_mut());
        self.paragraphs.insert(pos.para + 1, new_para);
        DocPos::new(pos.para + 1, 0)
    }

    /// Delete `range` and return its start.
    pub fn delete(&mut self, range: Range<DocPos>) -> DocPos {
        let Range { start, end } = range;
        if start >= end {
            return start;
        }
        if start.para == end.para {
            self.paragraphs[start.para].delete_text(start.offset..end.offset);
            return start;
        }
        let start_len = self.paragraphs[start.para].len();
        self.paragraphs[start.para].delete_text(start.offset..start_len);
        self.paragraphs[end.para].delete_text(0..end.offset);
        let tail = self.paragraphs.remove(end.para);
        self.paragraphs.drain(start.para + 1..end.para);
        let left = &mut self.paragraphs[start.para];
        left.keep_only_active_version();
        left.segments_mut().extend(tail.segments().iter().cloned());
        normalize_segments(left.segments_mut());
        start
    }

    /// Rendered text in `range`, paragraphs joined by `\n`.
    pub fn text_in(&self, range: Range<DocPos>) -> String {
        self.collect_in(range, |p, s, e| p.text()[s..e].to_string())
    }

    /// Like `text_in`, but ghosted text is left out.
    pub fn export_text_in(&self, range: Range<DocPos>) -> String {
        self.collect_in(range, |p, s, e| {
            let text = p.text();
            p.spans()
                .iter()
                .filter(|span| !span.ghost)
                .filter_map(|span| {
                    let a = span.range.start.max(s);
                    let b = span.range.end.min(e);
                    (a < b).then(|| &text[a..b])
                })
                .collect()
        })
    }

    fn collect_in(
        &self,
        range: Range<DocPos>,
        slice: impl Fn(&Paragraph, usize, usize) -> String,
    ) -> String {
        let mut out = String::new();
        for i in range.start.para..=range.end.para {
            let p = &self.paragraphs[i];
            let start = if i == range.start.para { range.start.offset } else { 0 };
            let end = if i == range.end.para { range.end.offset } else { p.len() };
            if i > range.start.para {
                out.push('\n');
            }
            out.push_str(&slice(p, start, end));
        }
        out
    }

    /// The whole document's rendered text, paragraphs joined by `\n`.
    pub fn flat_text(&self) -> String {
        self.paragraphs.iter().map(Paragraph::text).collect::<Vec<_>>().join("\n")
    }

    pub fn flat_offset(&self, pos: DocPos) -> usize {
        self.paragraphs[..pos.para].iter().map(|p| p.len() + 1).sum::<usize>() + pos.offset
    }

    pub fn pos_from_flat(&self, flat: usize) -> DocPos {
        let mut rest = flat;
        for (i, p) in self.paragraphs.iter().enumerate() {
            let len = p.len();
            if rest <= len {
                return self.clamp(DocPos::new(i, rest));
            }
            rest -= len + 1;
        }
        self.end_pos()
    }
}

//! Alternates: word-level option groups and paragraph versions.

use std::ops::Range;

use crate::model::{
    AltOption, Document, ParaVersion, Paragraph, SegKind, Segment, Source, normalize_segments,
};
use crate::pos::DocPos;

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum OpError {
    #[error("select some text first")]
    EmptySelection,
    #[error("selection must be within one paragraph")]
    MultiParagraph,
    #[error("nothing to do here")]
    NothingHere,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AltLevel {
    Word,
    Paragraph,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AltInfo {
    pub level: AltLevel,
    pub index: usize,
    pub count: usize,
    pub span: Range<usize>,
}

impl Paragraph {
    /// The alternate at `offset`; edges count as inside and the earlier group wins.
    pub fn alt_at(&self, offset: usize) -> Option<usize> {
        let ranges = self.segment_ranges();
        (0..ranges.len()).find(|&i| {
            self.segments()[i].is_alt() && ranges[i].start <= offset && offset <= ranges[i].end
        })
    }

    /// The alternate whose span starts at `start` (the group being edited may be empty).
    pub fn alt_starting_at(&self, start: usize) -> Option<usize> {
        let ranges = self.segment_ranges();
        (0..ranges.len()).find(|&i| self.segments()[i].is_alt() && ranges[i].start == start)
    }

    /// Grow `range` so neither edge falls strictly inside an alternate.
    pub fn expand_to_alt_boundaries(&self, range: Range<usize>) -> Range<usize> {
        let (mut start, mut end) = (range.start, range.end);
        for (seg, r) in self.segments().iter().zip(self.segment_ranges()) {
            if seg.is_alt() {
                if r.start < start && start < r.end {
                    start = r.start;
                }
                if r.start < end && end < r.end {
                    end = r.end;
                }
            }
        }
        start..end
    }

    /// Ensure segment boundaries at the edges of `range` (after expanding it around alternates).
    /// Returns the expanded byte range and the indices of the segments covering it.
    pub(crate) fn isolate(&mut self, range: Range<usize>) -> (Range<usize>, Range<usize>) {
        let range = self.expand_to_alt_boundaries(range);
        self.split_segments_at(range.end);
        self.split_segments_at(range.start);
        let ranges = self.segment_ranges();
        let first = ranges
            .iter()
            .position(|r| r.start >= range.start && !r.is_empty())
            .unwrap_or(ranges.len());
        let end = ranges
            .iter()
            .rposition(|r| r.end <= range.end && !r.is_empty())
            .map_or(first, |i| i + 1);
        (range, first..end.max(first))
    }
}

impl Document {
    /// Find the alternate exactly covering `range`, or turn `range` into a one-option alternate.
    /// Returns the segment index.
    fn ensure_alt(&mut self, para: usize, range: Range<usize>) -> Result<usize, OpError> {
        if range.is_empty() {
            return Err(OpError::EmptySelection);
        }
        let p = &mut self.paragraphs[para];
        let ranges = p.segment_ranges();
        if let Some(i) = (0..ranges.len()).find(|&i| p.segments()[i].is_alt() && ranges[i] == range) {
            return Ok(i);
        }
        let (range, segs) = p.isolate(range);
        let removed: Vec<Segment> = p.segments_mut().drain(segs.clone()).collect();
        let text: String = removed.iter().map(Segment::text).collect();
        let ghost = removed.iter().all(|s| s.ghost);
        p.segments_mut().insert(segs.start, Segment::alt(vec![AltOption::human(text)], 0, ghost));
        normalize_segments(p.segments_mut());
        Ok(p.alt_starting_at(range.start).expect("alternate was just inserted"))
    }

    /// Make an alternate from a selection (or add an option to the group it exactly covers).
    /// The new option is a copy of the current text and becomes active. Returns the group's span.
    pub fn make_alt(&mut self, para: usize, range: Range<usize>) -> Result<Range<usize>, OpError> {
        let seg = self.ensure_alt(para, range)?;
        let p = &mut self.paragraphs[para];
        if let SegKind::Alt { options, active } = &mut p.segments_mut()[seg].kind {
            let copy = AltOption::human(options[*active].text.clone());
            options.push(copy);
            *active = options.len() - 1;
        }
        Ok(p.segment_ranges()[seg].clone())
    }

    /// Append AI-written options to the group at `range` (creating it) and show the first one.
    pub fn add_ai_alternates(
        &mut self,
        para: usize,
        range: Range<usize>,
        texts: Vec<String>,
        source: Source,
    ) -> Result<Range<usize>, OpError> {
        if texts.is_empty() {
            return Err(OpError::NothingHere);
        }
        let seg = self.ensure_alt(para, range)?;
        let p = &mut self.paragraphs[para];
        if let SegKind::Alt { options, active } = &mut p.segments_mut()[seg].kind {
            *active = options.len();
            options.extend(texts.into_iter().map(|text| AltOption { text, source: source.clone() }));
        }
        Ok(p.segment_ranges()[seg].clone())
    }

    /// Clone the active version as a new, active version. Returns its index.
    pub fn make_para_version(&mut self, para: usize) -> usize {
        let p = &mut self.paragraphs[para];
        let segments = p.segments().to_vec();
        p.versions.push(ParaVersion { segments, source: Source::Human });
        p.active = p.versions.len() - 1;
        p.active
    }

    /// Append AI-written paragraph versions and show the first one.
    pub fn add_ai_versions(
        &mut self,
        para: usize,
        texts: Vec<String>,
        source: Source,
    ) -> Result<(), OpError> {
        if texts.is_empty() {
            return Err(OpError::NothingHere);
        }
        let p = &mut self.paragraphs[para];
        p.active = p.versions.len();
        p.versions.extend(texts.into_iter().map(|text| ParaVersion {
            segments: vec![Segment::plain(text, false)],
            source: source.clone(),
        }));
        Ok(())
    }

    pub fn alt_info(&self, pos: DocPos) -> Option<AltInfo> {
        let p = self.paragraphs.get(pos.para)?;
        if let Some(i) = p.alt_at(pos.offset) {
            if let SegKind::Alt { options, active } = &p.segments()[i].kind {
                return Some(AltInfo {
                    level: AltLevel::Word,
                    index: *active,
                    count: options.len(),
                    span: p.segment_ranges()[i].clone(),
                });
            }
        }
        (p.versions.len() > 1).then(|| AltInfo {
            level: AltLevel::Paragraph,
            index: p.active,
            count: p.versions.len(),
            span: 0..p.len(),
        })
    }

    /// Cycle the alternate at `pos`, or else the paragraph's versions.
    pub fn cycle(&mut self, pos: DocPos, forward: bool) -> Option<AltInfo> {
        let step = |i: usize, n: usize| if forward { (i + 1) % n } else { (i + n - 1) % n };
        let p = &mut self.paragraphs[pos.para];
        if let Some(i) = p.alt_at(pos.offset) {
            let start = p.segment_ranges()[i].start;
            if let SegKind::Alt { options, active } = &mut p.segments_mut()[i].kind {
                *active = step(*active, options.len());
                let len = options[*active].text.len();
                return Some(AltInfo {
                    level: AltLevel::Word,
                    index: *active,
                    count: options.len(),
                    span: start..start + len,
                });
            }
        }
        if p.versions.len() > 1 {
            p.active = step(p.active, p.versions.len());
            return Some(AltInfo {
                level: AltLevel::Paragraph,
                index: p.active,
                count: p.versions.len(),
                span: 0..p.len(),
            });
        }
        None
    }

    /// Collapse the alternate at `pos` to its active option, or drop the other versions.
    pub fn accept(&mut self, pos: DocPos) -> bool {
        let p = &mut self.paragraphs[pos.para];
        if let Some(i) = p.alt_at(pos.offset) {
            let seg = &mut p.segments_mut()[i];
            seg.kind = SegKind::Plain(seg.text().to_string());
            normalize_segments(p.segments_mut());
            return true;
        }
        if p.versions.len() > 1 {
            p.keep_only_active_version();
            return true;
        }
        false
    }

    /// Delete the active option (or version) at `pos`. Returns the affected span afterwards.
    pub fn delete_option(&mut self, pos: DocPos) -> Option<Range<usize>> {
        let p = &mut self.paragraphs[pos.para];
        if let Some(i) = p.alt_at(pos.offset) {
            let start = p.segment_ranges()[i].start;
            let seg = &mut p.segments_mut()[i];
            let remaining = match &mut seg.kind {
                SegKind::Alt { options, active } => {
                    if options.len() > 1 {
                        options.remove(*active);
                        *active = (*active).min(options.len() - 1);
                    }
                    (options.len() == 1).then(|| options[0].text.clone())
                }
                SegKind::Plain(_) => None,
            };
            if let Some(text) = remaining {
                seg.kind = SegKind::Plain(text);
            }
            let len = seg.text().len();
            normalize_segments(p.segments_mut());
            return Some(start..start + len);
        }
        if p.versions.len() > 1 {
            let active = p.active;
            p.versions.remove(active);
            p.active = active.min(p.versions.len() - 1);
            return Some(0..p.len());
        }
        None
    }

    /// Replace `local` (a byte range in the active option of alternate `seg`) with `text`.
    /// Unlike `delete`, the option may become empty; call `finish_alt_edit` when editing ends.
    pub fn edit_alt(&mut self, para: usize, seg: usize, local: Range<usize>, text: &str) {
        self.paragraphs[para].segments_mut()[seg].text_mut().replace_range(local, text);
    }

    /// End alternate editing: drop an empty active option (showing the previous one), and turn a
    /// group left with a single option into plain text.
    pub fn finish_alt_edit(&mut self, para: usize, seg: usize) {
        let Some(p) = self.paragraphs.get_mut(para) else { return };
        let Some(segment) = p.segments_mut().get_mut(seg) else { return };
        let collapse = match &mut segment.kind {
            SegKind::Alt { options, active } => {
                if options[*active].text.is_empty() && options.len() > 1 {
                    options.remove(*active);
                    *active = (*active).saturating_sub(1);
                }
                (options.len() == 1).then(|| options[0].text.clone())
            }
            SegKind::Plain(_) => None,
        };
        if let Some(text) = collapse {
            segment.kind = SegKind::Plain(text);
        }
        normalize_segments(p.segments_mut());
    }
}

//! Ghosting: dimming text so it can be judged without being deleted.

use std::ops::Range;

use crate::alternates::OpError;
use crate::model::{Document, normalize_segments};

impl Document {
    /// Set the ghost flag on `range`, grown to cover whole alternates. Returns that range.
    pub fn set_ghost(
        &mut self,
        para: usize,
        range: Range<usize>,
        ghost: bool,
    ) -> Result<Range<usize>, OpError> {
        if range.is_empty() {
            return Err(OpError::EmptySelection);
        }
        let p = &mut self.paragraphs[para];
        let (range, segs) = p.isolate(range);
        for seg in &mut p.segments_mut()[segs] {
            seg.ghost = ghost;
        }
        normalize_segments(p.segments_mut());
        Ok(range)
    }

    /// Ghost `range`, or revive it if it is entirely ghosted already.
    pub fn toggle_ghost(&mut self, para: usize, range: Range<usize>) -> Result<Range<usize>, OpError> {
        if range.is_empty() {
            return Err(OpError::EmptySelection);
        }
        let p = &self.paragraphs[para];
        let range = p.expand_to_alt_boundaries(range);
        let all_ghost = p
            .spans()
            .iter()
            .filter(|s| s.range.start < range.end && range.start < s.range.end)
            .all(|s| s.ghost);
        self.set_ghost(para, range, !all_ghost)
    }
}

//! The overflow panel's storage: text stashed outside the document.

use std::ops::Range;

use chrono::{DateTime, Utc};

use crate::model::{Document, OverflowId, OverflowItem};
use crate::pos::DocPos;

impl Document {
    /// Move the export text of `range` into overflow. Returns `None` if there is nothing to stash.
    pub fn to_overflow(&mut self, range: Range<DocPos>, now: DateTime<Utc>) -> Option<OverflowId> {
        let text = self.export_text_in(range.clone());
        if text.trim().is_empty() {
            return None;
        }
        let from = self.paragraphs.get(range.start.para).map(|p| p.id);
        self.delete(range);
        Some(self.push_overflow(text, now, from))
    }

    /// Move a whole paragraph into overflow. The document always keeps at least one paragraph.
    pub fn paragraph_to_overflow(&mut self, para: usize, now: DateTime<Utc>) -> Option<OverflowId> {
        let text = self.paragraphs[para].export_text();
        if text.trim().is_empty() {
            return None;
        }
        let removed = self.paragraphs.remove(para);
        if self.paragraphs.is_empty() {
            let p = self.new_paragraph("");
            self.paragraphs.push(p);
        }
        Some(self.push_overflow(text, now, Some(removed.id)))
    }

    fn push_overflow(
        &mut self,
        text: String,
        now: DateTime<Utc>,
        from: Option<crate::model::ParaId>,
    ) -> OverflowId {
        let id = OverflowId(self.fresh_id());
        self.overflow.push(OverflowItem { id, text, created_at: now, from_paragraph: from });
        id
    }

    /// Insert an overflow item's text at `pos`. Returns the position after the inserted text.
    pub fn insert_overflow(&mut self, id: OverflowId, pos: DocPos, remove: bool) -> Option<DocPos> {
        let ix = self.overflow.iter().position(|o| o.id == id)?;
        let text = self.overflow[ix].text.clone();
        if remove {
            self.overflow.remove(ix);
        }
        Some(self.insert(pos, &text))
    }

    pub fn remove_overflow(&mut self, id: OverflowId) -> bool {
        let before = self.overflow.len();
        self.overflow.retain(|o| o.id != id);
        self.overflow.len() != before
    }
}

//! Snapshot-based undo/redo with coalescing of consecutive typing.

use std::time::{Duration, Instant};

pub const COALESCE_WINDOW: Duration = Duration::from_secs(1);

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum EditKind {
    /// A single-character insert or delete in paragraph `para`.
    Typing { para: usize },
    Other,
}

pub struct History<S> {
    undo: Vec<S>,
    redo: Vec<S>,
    last: Option<(EditKind, Instant)>,
    limit: usize,
}

impl<S: Clone> History<S> {
    pub fn new(limit: usize) -> Self {
        Self { undo: Vec::new(), redo: Vec::new(), last: None, limit: limit.max(1) }
    }

    /// Call before applying an edit. `before` produces the pre-edit state and only runs when a new
    /// undo step is needed.
    pub fn record(&mut self, kind: EditKind, now: Instant, before: impl FnOnce() -> S) {
        let coalesce = matches!(
            (kind, self.last),
            (EditKind::Typing { para }, Some((EditKind::Typing { para: last_para }, at)))
                if para == last_para && now.saturating_duration_since(at) < COALESCE_WINDOW
        );
        if !coalesce {
            self.undo.push(before());
            if self.undo.len() > self.limit {
                self.undo.remove(0);
            }
        }
        self.redo.clear();
        self.last = Some((kind, now));
    }

    pub fn break_coalescing(&mut self) {
        self.last = None;
    }

    pub fn undo(&mut self, current: S) -> Option<S> {
        let previous = self.undo.pop()?;
        self.redo.push(current);
        self.last = None;
        Some(previous)
    }

    pub fn redo(&mut self, current: S) -> Option<S> {
        let next = self.redo.pop()?;
        self.undo.push(current);
        self.last = None;
        Some(next)
    }

    pub fn can_undo(&self) -> bool {
        !self.undo.is_empty()
    }

    pub fn can_redo(&self) -> bool {
        !self.redo.is_empty()
    }
}

//! Markdown export plus a JSON sidecar that keeps the full document model.

use std::fs::{self, File};
use std::io::{self, Write};
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};
use sha2::{Digest, Sha256};

use crate::model::Document;

pub const FORMAT_VERSION: u32 = 1;

#[derive(Debug, thiserror::Error)]
pub enum StorageError {
    #[error("{0}")]
    Io(#[from] io::Error),
    #[error("could not encode sidecar: {0}")]
    Json(#[from] serde_json::Error),
}

#[derive(Debug)]
pub struct Opened {
    pub document: Document,
    pub notices: Vec<String>,
}

#[derive(Serialize)]
struct SidecarOut<'a> {
    format_version: u32,
    md_hash: String,
    document: &'a Document,
}

#[derive(Deserialize)]
struct SidecarHeader {
    format_version: u32,
}

#[derive(Deserialize)]
struct SidecarIn {
    md_hash: String,
    document: Document,
}

pub fn sidecar_path(md: &Path) -> PathBuf {
    let mut name = md.as_os_str().to_owned();
    name.push(".tulis.json");
    PathBuf::from(name)
}

pub fn export_markdown(doc: &Document) -> String {
    let paragraphs = doc.export_paragraphs();
    if paragraphs.is_empty() {
        return String::new();
    }
    let mut md = paragraphs.join("\n\n");
    md.push('\n');
    md
}

/// Split Markdown into paragraphs on blank lines; lines within a paragraph are joined with spaces.
pub fn parse_markdown(md: &str) -> Vec<String> {
    let mut out = Vec::new();
    let mut current: Vec<&str> = Vec::new();
    for line in md.lines() {
        let line = line.trim();
        if line.is_empty() {
            if !current.is_empty() {
                out.push(current.join(" "));
                current.clear();
            }
        } else {
            current.push(line);
        }
    }
    if !current.is_empty() {
        out.push(current.join(" "));
    }
    out
}

fn hash_hex(bytes: &[u8]) -> String {
    hex::encode(Sha256::digest(bytes))
}

fn atomic_write(path: &Path, bytes: &[u8]) -> io::Result<()> {
    let dir = match path.parent() {
        Some(p) if !p.as_os_str().is_empty() => p,
        _ => Path::new("."),
    };
    let name = path
        .file_name()
        .ok_or_else(|| io::Error::new(io::ErrorKind::InvalidInput, "path has no file name"))?;
    let tmp = dir.join(format!(".{}.tmp", name.to_string_lossy()));
    {
        let mut file = File::create(&tmp)?;
        file.write_all(bytes)?;
        file.sync_all()?;
    }
    fs::rename(&tmp, path)
}

/// Write the Markdown export, then the sidecar. Each file is replaced atomically.
pub fn save(doc: &Document, md_path: &Path) -> Result<(), StorageError> {
    let md = export_markdown(doc);
    atomic_write(md_path, md.as_bytes())?;
    let sidecar = SidecarOut {
        format_version: FORMAT_VERSION,
        md_hash: hash_hex(md.as_bytes()),
        document: doc,
    };
    let json = serde_json::to_vec_pretty(&sidecar)?;
    atomic_write(&sidecar_path(md_path), &json)?;
    Ok(())
}

pub fn open(md_path: &Path) -> Result<Opened, StorageError> {
    let bytes = fs::read(md_path)?;
    let texts = parse_markdown(&String::from_utf8_lossy(&bytes));
    let mut notices = Vec::new();
    let document = match read_sidecar(&sidecar_path(md_path), &mut notices) {
        None => Document::from_texts(&texts),
        Some(side) if side.md_hash == hash_hex(&bytes) => side.document,
        Some(side) => {
            let (doc, lost) = reconcile(&texts, side.document);
            let name = md_path
                .file_name()
                .map(|n| n.to_string_lossy().into_owned())
                .unwrap_or_default();
            notices.push(format!(
                "{name} changed outside Tulis; {lost} paragraphs lost alternates/ghosts"
            ));
            doc
        }
    };
    Ok(Opened { document, notices })
}

fn read_sidecar(path: &Path, notices: &mut Vec<String>) -> Option<SidecarIn> {
    let bytes = match fs::read(path) {
        Ok(bytes) => bytes,
        Err(e) if e.kind() == io::ErrorKind::NotFound => return None,
        Err(e) => {
            notices.push(format!("Ignoring unreadable sidecar: {e}"));
            return None;
        }
    };
    match serde_json::from_slice::<SidecarHeader>(&bytes) {
        Ok(header) if header.format_version == FORMAT_VERSION => {}
        Ok(header) => {
            notices.push(format!(
                "Ignoring sidecar with unknown format version {}",
                header.format_version
            ));
            return None;
        }
        Err(e) => {
            notices.push(format!("Ignoring unreadable sidecar: {e}"));
            return None;
        }
    }
    match serde_json::from_slice::<SidecarIn>(&bytes) {
        Ok(sidecar) => Some(sidecar),
        Err(e) => {
            notices.push(format!("Ignoring unreadable sidecar: {e}"));
            None
        }
    }
}

/// Rebuild a document from Markdown paragraphs, reusing sidecar paragraphs whose export text
/// matches exactly (each at most once). Overflow is kept. Returns the document and the number of
/// sidecar paragraphs with alternates/ghosts that could not be matched.
pub fn reconcile(texts: &[String], mut sidecar: Document) -> (Document, usize) {
    let old = std::mem::take(&mut sidecar.paragraphs);
    let old_texts: Vec<String> = old.iter().map(|p| p.export_text()).collect();
    let mut used = vec![false; old.len()];
    let mut paragraphs = Vec::with_capacity(texts.len());
    for text in texts {
        match (0..old.len()).find(|&i| !used[i] && old_texts[i] == *text) {
            Some(i) => {
                used[i] = true;
                paragraphs.push(old[i].clone());
            }
            None => {
                let p = sidecar.new_paragraph(text.as_str());
                paragraphs.push(p);
            }
        }
    }
    let lost = old.iter().zip(&used).filter(|(p, used)| !**used && p.has_metadata()).count();
    if paragraphs.is_empty() {
        let p = sidecar.new_paragraph("");
        paragraphs.push(p);
    }
    sidecar.paragraphs = paragraphs;
    (sidecar, lost)
}

//! Cursor motions over document text.

use std::ops::Range;

use unicode_segmentation::UnicodeSegmentation;

use crate::model::Document;
use crate::pos::DocPos;

#[derive(Clone, Copy, PartialEq, Eq)]
enum Class {
    Blank,
    Word,
    Punct,
}

fn class(c: char) -> Class {
    if c.is_whitespace() {
        Class::Blank
    } else if c.is_alphanumeric() || c == '_' {
        Class::Word
    } else {
        Class::Punct
    }
}

pub fn prev_grapheme(doc: &Document, pos: DocPos) -> DocPos {
    if pos.offset == 0 {
        return if pos.para == 0 {
            pos
        } else {
            DocPos::new(pos.para - 1, doc.paragraphs[pos.para - 1].len())
        };
    }
    let text = doc.paragraphs[pos.para].text();
    let offset = text
        .grapheme_indices(true)
        .rev()
        .find_map(|(i, _)| (i < pos.offset).then_some(i))
        .unwrap_or(0);
    DocPos::new(pos.para, offset)
}

pub fn next_grapheme(doc: &Document, pos: DocPos) -> DocPos {
    let text = doc.paragraphs[pos.para].text();
    if pos.offset >= text.len() {
        return if pos.para + 1 < doc.paragraphs.len() { DocPos::new(pos.para + 1, 0) } else { pos };
    }
    let offset = text
        .grapheme_indices(true)
        .find_map(|(i, _)| (i > pos.offset).then_some(i))
        .unwrap_or(text.len());
    DocPos::new(pos.para, offset)
}

pub fn next_word_start(doc: &Document, pos: DocPos) -> DocPos {
    let text = doc.flat_text();
    let start = doc.flat_offset(pos);
    let mut chars = text[start..].char_indices().map(|(i, c)| (start + i, c)).peekable();
    let Some(&(_, first)) = chars.peek() else { return doc.end_pos() };
    let first_class = class(first);
    if first_class != Class::Blank {
        while chars.next_if(|&(_, c)| class(c) == first_class).is_some() {}
    }
    while chars.next_if(|&(_, c)| class(c) == Class::Blank).is_some() {}
    match chars.peek() {
        Some(&(i, _)) => doc.pos_from_flat(i),
        None => doc.end_pos(),
    }
}

pub fn prev_word_start(doc: &Document, pos: DocPos) -> DocPos {
    let text = doc.flat_text();
    let end = doc.flat_offset(pos);
    let chars: Vec<(usize, char)> = text[..end].char_indices().collect();
    let mut i = chars.len();
    while i > 0 && class(chars[i - 1].1) == Class::Blank {
        i -= 1;
    }
    if i == 0 {
        return DocPos::default();
    }
    let word_class = class(chars[i - 1].1);
    while i > 0 && class(chars[i - 1].1) == word_class {
        i -= 1;
    }
    doc.pos_from_flat(chars[i].0)
}

pub fn word_end(doc: &Document, pos: DocPos) -> DocPos {
    let text = doc.flat_text();
    let start = doc.flat_offset(pos);
    let chars: Vec<(usize, char)> = text[start..].char_indices().map(|(i, c)| (start + i, c)).collect();
    let mut i = 1;
    while i < chars.len() && class(chars[i].1) == Class::Blank {
        i += 1;
    }
    if i >= chars.len() {
        return doc.end_pos();
    }
    let word_class = class(chars[i].1);
    while i + 1 < chars.len() && class(chars[i + 1].1) == word_class {
        i += 1;
    }
    doc.pos_from_flat(chars[i].0)
}

pub fn next_paragraph(doc: &Document, pos: DocPos) -> DocPos {
    if pos.para + 1 < doc.paragraphs.len() { DocPos::new(pos.para + 1, 0) } else { doc.end_pos() }
}

pub fn prev_paragraph(_doc: &Document, pos: DocPos) -> DocPos {
    if pos.offset > 0 {
        DocPos::new(pos.para, 0)
    } else if pos.para > 0 {
        DocPos::new(pos.para - 1, 0)
    } else {
        pos
    }
}

/// The run of same-class characters at `offset` (the char before it when at the end).
pub fn word_range_at(text: &str, offset: usize) -> Range<usize> {
    let chars: Vec<(usize, char)> = text.char_indices().collect();
    let ix = match chars.iter().position(|&(i, _)| i == offset) {
        Some(ix) => ix,
        None if !chars.is_empty() => chars.len() - 1,
        None => return offset..offset,
    };
    let word_class = class(chars[ix].1);
    let mut start = ix;
    while start > 0 && class(chars[start - 1].1) == word_class {
        start -= 1;
    }
    let mut end = ix;
    while end + 1 < chars.len() && class(chars[end + 1].1) == word_class {
        end += 1;
    }
    chars[start].0..chars[end].0 + chars[end].1.len_utf8()
}

//! Vim mode: a key-by-key state machine that produces abstract editor commands.

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum VimKey {
    Char(char),
    Escape,
    Ctrl(char),
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub enum Mode {
    #[default]
    Normal,
    Insert,
    Visual,
    VisualLine,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Motion {
    Left,
    Right,
    Up,
    Down,
    WordForward,
    WordBackward,
    WordEnd,
    LineStart,
    FirstNonBlank,
    LineEnd,
    DocStart,
    DocEnd,
    ParagraphForward,
    ParagraphBackward,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Operator {
    Delete,
    Change,
    Yank,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum InsertAt {
    Cursor,
    After,
    LineStart,
    LineEnd,
    ParagraphBelow,
    ParagraphAbove,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum VimCommand {
    Move { motion: Motion, count: usize },
    Operate { op: Operator, motion: Motion, count: usize },
    OperateParagraphs { op: Operator, count: usize },
    OperateSelection { op: Operator, linewise: bool },
    DeleteChars { count: usize },
    Put { before: bool, count: usize },
    EnterInsert(InsertAt),
    BeginVisual,
    EndVisual,
    ExitInsert,
    Undo { count: usize },
    Redo { count: usize },
    CycleAlt { forward: bool, count: usize },
    ToggleGhost,
}

#[derive(Debug, Default)]
pub struct Vim {
    mode: Mode,
    count: Option<usize>,
    op: Option<(Operator, Option<usize>)>,
    prefix: Option<char>,
}

fn motion_for(c: char) -> Option<Motion> {
    Some(match c {
        'h' => Motion::Left,
        'l' => Motion::Right,
        'j' => Motion::Down,
        'k' => Motion::Up,
        'w' => Motion::WordForward,
        'b' => Motion::WordBackward,
        'e' => Motion::WordEnd,
        '0' => Motion::LineStart,
        '^' => Motion::FirstNonBlank,
        '$' => Motion::LineEnd,
        'G' => Motion::DocEnd,
        '}' => Motion::ParagraphForward,
        '{' => Motion::ParagraphBackward,
        _ => return None,
    })
}

fn operator_for(c: char) -> Option<Operator> {
    Some(match c {
        'd' => Operator::Delete,
        'c' => Operator::Change,
        'y' => Operator::Yank,
        _ => return None,
    })
}

impl Vim {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn mode(&self) -> Mode {
        self.mode
    }

    pub fn set_mode(&mut self, mode: Mode) {
        self.mode = mode;
        self.reset();
    }

    pub fn is_visual(&self) -> bool {
        matches!(self.mode, Mode::Visual | Mode::VisualLine)
    }

    pub fn feed(&mut self, key: VimKey) -> Vec<VimCommand> {
        if self.mode == Mode::Insert {
            if key == VimKey::Escape {
                self.mode = Mode::Normal;
                return vec![VimCommand::ExitInsert];
            }
            return Vec::new();
        }
        match key {
            VimKey::Escape => {
                self.reset();
                if self.is_visual() {
                    self.mode = Mode::Normal;
                    vec![VimCommand::EndVisual]
                } else {
                    Vec::new()
                }
            }
            VimKey::Ctrl('r') => {
                let count = self.count();
                self.reset();
                vec![VimCommand::Redo { count }]
            }
            VimKey::Ctrl(_) => {
                self.reset();
                Vec::new()
            }
            VimKey::Char(c) => self.feed_char(c),
        }
    }

    fn reset(&mut self) {
        self.count = None;
        self.op = None;
        self.prefix = None;
    }

    fn count(&self) -> usize {
        self.count.unwrap_or(1) * self.op.and_then(|(_, c)| c).unwrap_or(1)
    }

    fn feed_char(&mut self, c: char) -> Vec<VimCommand> {
        if let Some(prefix) = self.prefix.take() {
            return self.feed_prefixed(prefix, c);
        }
        if let Some(digit) = c.to_digit(10) {
            if digit != 0 || self.count.is_some() {
                let n = self.count.unwrap_or(0).saturating_mul(10).saturating_add(digit as usize);
                self.count = Some(n);
                return Vec::new();
            }
        }
        if let Some(motion) = motion_for(c) {
            return self.motion(motion);
        }
        if matches!(c, 'g' | ']' | '[') {
            self.prefix = Some(c);
            return Vec::new();
        }
        let visual = self.is_visual();
        let linewise = self.mode == Mode::VisualLine;
        if let Some(op) = operator_for(c) {
            if visual {
                self.reset();
                self.mode = if op == Operator::Change { Mode::Insert } else { Mode::Normal };
                return vec![VimCommand::OperateSelection { op, linewise }];
            }
            return match self.op {
                Some((pending, _)) if pending == op => {
                    let count = self.count();
                    self.reset();
                    if op == Operator::Change {
                        self.mode = Mode::Insert;
                    }
                    vec![VimCommand::OperateParagraphs { op, count }]
                }
                Some(_) => {
                    self.reset();
                    Vec::new()
                }
                None => {
                    self.op = Some((op, self.count.take()));
                    Vec::new()
                }
            };
        }
        if self.op.is_some() {
            self.reset();
            return Vec::new();
        }
        let count = self.count();
        self.reset();
        match c {
            'x' if visual => {
                self.mode = Mode::Normal;
                vec![VimCommand::OperateSelection { op: Operator::Delete, linewise }]
            }
            'x' => vec![VimCommand::DeleteChars { count }],
            'p' => vec![VimCommand::Put { before: false, count }],
            'P' => vec![VimCommand::Put { before: true, count }],
            'u' => vec![VimCommand::Undo { count }],
            'v' => self.toggle_visual(Mode::Visual),
            'V' => self.toggle_visual(Mode::VisualLine),
            'i' | 'a' | 'I' | 'A' | 'o' | 'O' if !visual => {
                self.mode = Mode::Insert;
                let at = match c {
                    'i' => InsertAt::Cursor,
                    'a' => InsertAt::After,
                    'I' => InsertAt::LineStart,
                    'A' => InsertAt::LineEnd,
                    'o' => InsertAt::ParagraphBelow,
                    _ => InsertAt::ParagraphAbove,
                };
                vec![VimCommand::EnterInsert(at)]
            }
            _ => Vec::new(),
        }
    }

    fn feed_prefixed(&mut self, prefix: char, c: char) -> Vec<VimCommand> {
        match (prefix, c) {
            ('g', 'g') => self.motion(Motion::DocStart),
            ('g', 'h') if self.op.is_none() => {
                self.reset();
                if self.is_visual() {
                    self.mode = Mode::Normal;
                    vec![VimCommand::ToggleGhost, VimCommand::EndVisual]
                } else {
                    vec![VimCommand::ToggleGhost]
                }
            }
            (']' | '[', 'a') if self.op.is_none() => {
                let count = self.count();
                self.reset();
                vec![VimCommand::CycleAlt { forward: prefix == ']', count }]
            }
            _ => {
                self.reset();
                Vec::new()
            }
        }
    }

    fn toggle_visual(&mut self, target: Mode) -> Vec<VimCommand> {
        if self.mode == target {
            self.mode = Mode::Normal;
            vec![VimCommand::EndVisual]
        } else if self.is_visual() {
            self.mode = target;
            Vec::new()
        } else {
            self.mode = target;
            vec![VimCommand::BeginVisual]
        }
    }

    fn motion(&mut self, motion: Motion) -> Vec<VimCommand> {
        let count = self.count();
        let op = self.op.map(|(op, _)| op);
        self.reset();
        match op {
            Some(op) => {
                if op == Operator::Change {
                    self.mode = Mode::Insert;
                }
                vec![VimCommand::Operate { op, motion, count }]
            }
            None => vec![VimCommand::Move { motion, count }],
        }
    }
}

use std::sync::Arc;

pub use anthropic::{API_VERSION, AnthropicProvider, DEFAULT_BASE_URL};
pub use mock::MockProvider;
pub use openai::OpenAiCompatProvider;

use crate::config::{AiConfig, ProviderKind};

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CompletionRequest {
    pub system: String,
    pub user: String,
    pub max_tokens: u32,
}

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum AiError {
    #[error("Set ${0} to use AI")]
    MissingKey(String),
    #[error("AI request failed ({0}): {1}")]
    Http(u16, String),
    #[error("AI network error: {0}")]
    Network(String),
    #[error("Could not read AI response: {0}")]
    Parse(String),
    #[error("The model declined this request")]
    Refused,
    #[error("AI config: {0}")]
    Config(String),
}

pub trait LlmProvider: Send + Sync {
    fn complete(&self, req: &CompletionRequest) -> Result<String, AiError>;
    fn name(&self) -> &str;
    fn model(&self) -> &str;
}

/// Build the configured provider. `env` looks up environment variables (injected for tests).
pub fn provider_from_config(
    config: &AiConfig,
    env: impl Fn(&str) -> Option<String>,
) -> Result<Arc<dyn LlmProvider>, AiError> {
    let key = env(&config.api_key_env)
        .filter(|key| !key.trim().is_empty())
        .ok_or_else(|| AiError::MissingKey(config.api_key_env.clone()))?;
    match config.provider {
        ProviderKind::Anthropic => {
            let base = if config.base_url.is_empty() {
                DEFAULT_BASE_URL.to_string()
            } else {
                config.base_url.clone()
            };
            Ok(Arc::new(AnthropicProvider::new(key, config.model.clone(), base)))
        }
        ProviderKind::Openai => {
            if config.base_url.is_empty() {
                return Err(AiError::Config("base_url is required when provider = \"openai\"".into()));
            }
            Ok(Arc::new(OpenAiCompatProvider::new(key, config.model.clone(), config.base_url.clone())))
        }
    }
}

/// POST a JSON body and return the response text; non-2xx statuses become `AiError::Http`.
pub(crate) fn post_json(
    url: &str,
    headers: &[(&str, &str)],
    body: &serde_json::Value,
) -> Result<String, AiError> {
    let agent: ureq::Agent = ureq::Agent::config_builder()
        .timeout_global(Some(Duration::from_secs(30)))
        .http_status_as_error(false)
        .build()
        .into();
    let mut request = agent.post(url);
    for (name, value) in headers {
        request = request.header(*name, *value);
    }
    let mut response = request.send_json(body).map_err(|e| AiError::Network(e.to_string()))?;
    let status = response.status().as_u16();
    let text = response
        .body_mut()
        .read_to_string()
        .map_err(|e| AiError::Network(e.to_string()))?;
    if !(200..300).contains(&status) {
        return Err(AiError::Http(status, text.chars().take(200).collect()));
    }
    Ok(text)
}

//! Anthropic Messages API (raw HTTP; there is no official Rust SDK).

use serde_json::{Value, json};

use super::{AiError, CompletionRequest, LlmProvider, post_json};

pub const DEFAULT_BASE_URL: &str = "https://api.anthropic.com";
pub const API_VERSION: &str = "2026-10-21";

pub struct AnthropicProvider {
    api_key: String,
    model: String,
    base_url: String,
}

impl AnthropicProvider {
    pub fn new(api_key: String, model: String, base_url: String) -> Self {
        Self { api_key, model, base_url }
    }

    pub fn url(&self) -> String {
        format!("{}/v1/messages", self.base_url.trim_end_matches('/'))
    }

    pub fn request_body(&self, req: &CompletionRequest) -> Value {
        json!({
            "model": self.model,
            "max_tokens": req.max_tokens,
            "system": req.system,
            "messages": [{ "role": "user", "content": req.user }],
        })
    }

    pub fn parse_response(body: &str) -> Result<String, AiError> {
        let value: Value = serde_json::from_str(body).map_err(|e| AiError::Parse(e.to_string()))?;
        if value["stop_reason"] == "refusal" {
            return Err(AiError::Refused);
        }
        value["content"]
            .as_array()
            .and_then(|blocks| blocks.iter().find(|b| b["type"] == "text"))
            .and_then(|block| block["text"].as_str())
            .map(str::to_string)
            .ok_or_else(|| AiError::Parse("response has no text block".into()))
    }
}

impl LlmProvider for AnthropicProvider {
    fn complete(&self, req: &CompletionRequest) -> Result<String, AiError> {
        let body = self.request_body(req);
        let text = post_json(
            &self.url(),
            &[
                ("x-api-key", self.api_key.as_str()),
                ("anthropic-version", API_VERSION),
                ("content-type", "application/json"),
            ],
            &body,
        )?;
        Self::parse_response(&text)
    }

    fn name(&self) -> &str {
        "anthropic"
    }

    fn model(&self) -> &str {
        &self.model
    }

//! Prompts for AI alternates and AI trim, and parsing of their responses.

use std::ops::Range;

use super::CompletionRequest;
use crate::model::Paragraph;

const MAX_TOKENS: u32 = 4096;

pub fn alternates_request(paragraph: &str, target: &str, n: usize) -> CompletionRequest {
    let system = format!(
        "You are a writing assistant inside a distraction-free editor. The writer has marked a \
         passage and wants alternative phrasings of it. Write {n} alternatives that fit naturally \
         where the passage sits in its paragraph, keep its meaning, and match the writer's voice \
         and tense. Each alternative replaces only the marked passage, so do not repeat the \
         surrounding text. Reply with only a JSON array of {n} strings."
    );
    let user = format!("Paragraph:\n{paragraph}\n\nPassage to rewrite:\n{target}");
    CompletionRequest { system, user, max_tokens: MAX_TOKENS }
}

/// Alternatives from a response: a JSON array if present, otherwise one per line. Empty items,
/// repeats and copies of the original are dropped.
pub fn parse_alternates(response: &str, original: &str) -> Vec<String> {
    let raw = json_array(response).unwrap_or_else(|| {
        response
            .lines()
            .filter(|line| !line.trim_start().starts_with("```"))
            .map(|line| strip_list_marker(line).to_string())
            .collect()
    });
    let mut out: Vec<String> = Vec::new();
    for item in raw {
        let item = item.trim().to_string();
        if !item.is_empty() && item != original.trim() && !out.contains(&item) {
            out.push(item);
        }
    }
    out
}

pub fn trim_request(paragraph: &str) -> CompletionRequest {
    let system = "You are an editor helping a writer tighten a paragraph. Find words, phrases or \
                  sentences that could be deleted without losing meaning: filler, hedges, \
                  repetition, throat-clearing. Never rewrite or add text; only point at text to \
                  cut. Copy each cut exactly as it appears in the paragraph, including \
                  punctuation, so it can be found verbatim. Reply with only a JSON array of \
                  strings, or [] if nothing should be cut."
        .to_string();
    CompletionRequest { system, user: paragraph.to_string(), max_tokens: MAX_TOKENS }
}

pub fn parse_trim(response: &str) -> Vec<String> {
    json_array(response)
        .unwrap_or_default()
        .into_iter()
        .filter(|cut| !cut.trim().is_empty())
        .collect()
}

/// Map suggested cuts to byte ranges of the paragraph's rendered text. A cut must lie entirely in
/// non-ghost text and takes its first occurrence that doesn't overlap an earlier cut.
pub fn locate_trims(cuts: &[String], paragraph: &Paragraph) -> Vec<Range<usize>> {
    let text = paragraph.text();
    let mut visible: Vec<Range<usize>> = Vec::new();
    for span in paragraph.spans().into_iter().filter(|s| !s.ghost) {
        match visible.last_mut() {
            Some(last) if last.end == span.range.start => last.end = span.range.end,
            _ => visible.push(span.range),
        }
    }
    let mut found: Vec<Range<usize>> = Vec::new();
    for cut in cuts {
        let hit = text.match_indices(cut.as_str()).map(|(i, _)| i..i + cut.len()).find(|r| {
            visible.iter().any(|v| v.start <= r.start && r.end <= v.end)
                && !found.iter().any(|f| f.start < r.end && r.start < f.end)
        });
        if let Some(range) = hit {
            found.push(range);
        }
    }
    found.sort_by_key(|r| r.start);
    found
}

fn json_array(response: &str) -> Option<Vec<String>> {
    let start = response.find('[')?;
    let end = response.rfind(']')?;
    if end <= start {
        return None;
    }
    serde_json::from_str(&response[start..=end]).ok()
}

fn strip_list_marker(line: &str) -> &str {
    let mut text = line.trim();
    for marker in ["- ", "* ", "• "] {
        if let Some(rest) = text.strip_prefix(marker) {
            text = rest;
        }
    }
    let digits = text.len() - text.trim_start_matches(|c: char| c.is_ascii_digit()).len();
    if digits > 0 {
        let rest = &text[digits..];
        if let Some(rest) = rest.strip_prefix(". ").or_else(|| rest.strip_prefix(") ")) {
            text = rest;
        }
    }
    text.trim().trim_matches('"').trim()
}

use std::ops::Range;

pub fn offset_from_utf16(text: &str, utf16: usize) -> usize {
    let mut utf8 = 0;
    let mut units = 0;
    for ch in text.chars() {
        if units >= utf16 {
            break;
        }
        units += ch.len_utf16();
        utf8 += ch.len_utf8();
    }
    utf8
}

pub fn offset_to_utf16(text: &str, offset: usize) -> usize {
    let mut utf16 = 0;
    let mut bytes = 0;
    for ch in text.chars() {
        if bytes >= offset {
            break;
        }
        bytes += ch.len_utf8();
        utf16 += ch.len_utf16();
    }
    utf16
}

use std::ops::Range;

use gpui::{Font, Hsla, StrikethroughStyle, TextRun, UnderlineStyle, px};
use tulis_core::Span;

pub struct RunStyle {
    pub font: Font,
    pub color: Hsla,
    pub alt_underline: Hsla,
    pub ai_underline: Hsla,
    pub trim: Hsla,
    pub ghost_alpha: f32,
}

pub fn build_runs(
    text_len: usize,
    spans: &[Span],
    trims: &[Range<usize>],
    marked: Option<Range<usize>>,
    style: &RunStyle,
) -> Vec<TextRun> {
    let mut cuts = vec![0, text_len];
    for span in spans {
        cuts.extend([span.range.start, span.range.end]);
    }
    for range in trims.iter().chain(marked.iter()) {
        cuts.extend([range.start.min(text_len), range.end.min(text_len)]);
    }
    cuts.sort_unstable();
    cuts.dedup();
    cuts.windows(2)
        .filter(|w| w[0] < w[1])
        .map(|w| {
            let (a, b) = (w[0], w[1]);
            let span = spans.iter().find(|s| s.range.start <= a && b <= s.range.end);
            let ghost = span.is_some_and(|s| s.ghost);
            let alt = span.and_then(|s| s.alt);
            let in_marked = marked.as_ref().is_some_and(|m| m.start <= a && b <= m.end);
            let trimmed = trims.iter().any(|t| t.start <= a && b <= t.end);
            let mut color = style.color;
            if ghost {
                color.a *= style.ghost_alpha;
            }
            let underline = if in_marked {
                Some(UnderlineStyle { color: Some(style.color), thickness: px(1.), wavy: false })
            } else {
                alt.map(|mark| UnderlineStyle {
                    color: Some(if mark.ai { style.ai_underline } else { style.alt_underline }),
                    thickness: px(1.),
                    wavy: false,
                })
            };
            let strikethrough =
                trimmed.then(|| StrikethroughStyle { thickness: px(1.5), color: Some(style.trim) });
            TextRun {
                len: b - a,
                font: style.font.clone(),
                color,
                background_color: None,
                underline,
                strikethrough,
            }
        })
        .collect()
}

//! The last frame's layout: wrapped lines per paragraph, used for hit-testing and vertical moves.

use gpui::{Pixels, Point, WrappedLine, point, px};
use tulis_core::DocPos;

pub(crate) fn clamp_px(value: Pixels, low: Pixels, high: Pixels) -> Pixels {
    if value < low {
        low
    } else if value > high {
        high
    } else {
        value
    }
}

pub struct ParaLayout {
    /// Offset of the paragraph's top from the element's top.
    pub top: Pixels,
    pub line: WrappedLine,
    /// Byte offset at which each visual line starts.
    pub line_starts: Vec<usize>,
}

impl ParaLayout {
    pub fn new(top: Pixels, line: WrappedLine) -> Self {
        let mut line_starts = vec![0];
        for boundary in line.wrap_boundaries() {
            let run = &line.unwrapped_layout.runs[boundary.run_ix];
            line_starts.push(run.glyphs[boundary.glyph_ix].index);
        }
        Self { top, line, line_starts }
    }

    pub fn line_count(&self) -> usize {
        self.line_starts.len()
    }

    pub fn height(&self, line_height: Pixels) -> Pixels {
        line_height * self.line_count() as f32
    }

    pub fn visual_line_of(&self, offset: usize) -> usize {
        self.line_starts.partition_point(|&start| start <= offset).saturating_sub(1)
    }

    pub fn line_range(&self, k: usize) -> (usize, usize) {
        let end = self.line_starts.get(k + 1).copied().unwrap_or(self.line.len());
        (self.line_starts[k], end)
    }

    /// x of `offset` measured from the start of visual line `k`.
    pub fn x_in_line(&self, k: usize, offset: usize) -> Pixels {
        let layout = &self.line.unwrapped_layout;
        layout.x_for_index(offset) - layout.x_for_index(self.line_starts[k])
    }

    /// Position of `offset` relative to the paragraph's top-left corner.
    pub fn point_for(&self, offset: usize, line_height: Pixels) -> Point<Pixels> {
        let k = self.visual_line_of(offset);
        point(self.x_in_line(k, offset), line_height * k as f32)
    }

    pub fn index_for(&self, local: Point<Pixels>, line_height: Pixels) -> usize {
        match self.line.closest_index_for_position(local, line_height) {
            Ok(ix) | Err(ix) => ix,
        }
    }
}

pub struct LayoutCache {
    /// Window position of the element's top-left corner.
    pub origin: Point<Pixels>,
    pub width: Pixels,
    pub line_height: Pixels,
    pub paras: Vec<ParaLayout>,
}

impl LayoutCache {
    pub fn para_gap(&self) -> Pixels {
        self.line_height * 0.6
    }

    pub fn total_height(&self) -> Pixels {
        self.paras.last().map_or(self.line_height, |p| p.top + p.height(self.line_height))
    }

    /// Window position of the top of the caret at `pos`.
    pub fn window_point(&self, pos: DocPos) -> Option<Point<Pixels>> {
        let para = self.paras.get(pos.para)?;
        let local = para.point_for(pos.offset.min(para.line.len()), self.line_height);
        Some(point(self.origin.x + local.x, self.origin.y + para.top + local.y))
    }

    pub fn pos_for_window_point(&self, window_point: Point<Pixels>) -> DocPos {
        let x = window_point.x - self.origin.x;
        let y = window_point.y - self.origin.y;
        let gap = self.para_gap();
        let ix = self
            .paras
            .iter()
            .position(|p| y < p.top + p.height(self.line_height) + gap / 2.)
            .unwrap_or(self.paras.len().saturating_sub(1));
        let Some(para) = self.paras.get(ix) else { return DocPos::default() };
        let local_y = clamp_px(y - para.top, px(0.), para.height(self.line_height) - px(1.));
        let local_x = clamp_px(x, px(0.), self.width);
        DocPos::new(ix, para.index_for(point(local_x, local_y), self.line_height))
    }

    /// Move `lines` visual lines (negative = up) from `pos`, aiming for x = `goal_x`.
    pub fn vertical(&self, pos: DocPos, lines: isize, goal_x: Pixels) -> DocPos {
        if self.paras.is_empty() {
            return pos;
        }
        let mut para = pos.para.min(self.paras.len() - 1);
        let mut k = self.paras[para].visual_line_of(pos.offset) as isize + lines;
        while k < 0 {
            if para == 0 {
                return DocPos::new(0, 0);
            }
            para -= 1;
            k += self.paras[para].line_count() as isize;
        }
        while k >= self.paras[para].line_count() as isize {
            if para + 1 >= self.paras.len() {
                return DocPos::new(para, self.paras[para].line.len());
            }
            k -= self.paras[para].line_count() as isize;
            para += 1;
        }
        let y = self.line_height * k as f32 + self.line_height / 2.;
        DocPos::new(para, self.paras[para].index_for(point(goal_x, y), self.line_height))
    }

    /// Start and end of the visual line containing `pos`; a wrapped line's end excludes trailing spaces.
    pub fn line_bounds(&self, pos: DocPos, text: &str) -> (usize, usize) {
        let Some(para) = self.paras.get(pos.para) else { return (0, text.len()) };
        let k = para.visual_line_of(pos.offset);
        let (start, mut end) = para.line_range(k);
        end = end.min(text.len());
        if k + 1 < para.line_count() {
            while end > start && text[..end].ends_with(char::is_whitespace) {
                end -= text[..end].chars().next_back().map_or(1, char::len_utf8);
            }
        }
        (start, end)
    }

    pub fn x_for(&self, pos: DocPos) -> Pixels {
        let Some(para) = self.paras.get(pos.para) else { return px(0.) };
        para.x_in_line(para.visual_line_of(pos.offset), pos.offset.min(para.line.len()))
    }
}

/// Shape every paragraph at `width`. GPUI caches shaped lines between frames, so this is cheap.
fn build_layout(editor: &Editor, width: Pixels, origin: Point<Pixels>, window: &mut Window) -> LayoutCache {
    let font_size = px(editor.config.editor.font_size);
    let lh = line_height(editor);
    let style = RunStyle {
        font: font(editor.config.editor.font_family.clone()),
        color: theme::ink(),
        alt_underline: theme::alt_underline(),
        ai_underline: theme::ai_underline(),
        trim: theme::trim(),
        ghost_alpha: theme::GHOST_ALPHA,
    };
    let marked = editor
        .marked
        .clone()
        .map(|r| (editor.doc.pos_from_flat(r.start), editor.doc.pos_from_flat(r.end)));
    let mut top = px(0.);
    let mut paras = Vec::with_capacity(editor.doc.paragraphs.len());
    for (i, p) in editor.doc.paragraphs.iter().enumerate() {
        let text = p.text();
        let trims: Vec<_> = editor
            .trims
            .iter()
            .filter(|t| t.para_id == p.id)
            .map(|t| t.range.clone())
            .collect();
        let marked_here =
            marked.and_then(|(a, b)| (a.para == i && b.para == i).then(|| a.offset..b.offset));
        let runs = build_runs(text.len(), &p.spans(), &trims, marked_here, &style);
        let line = window
            .text_system()
            .shape_text(text.into(), font_size, &runs, Some(width), None)
            .ok()
            .and_then(|lines| lines.into_iter().next())
            .unwrap_or_default();
        let para = ParaLayout::new(top, line);
        top += para.height(lh) + lh * 0.6;
        paras.push(para);
    }
    LayoutCache { origin, width, line_height: lh, paras }
}

fn selection_quads(editor: &Editor, layout: &LayoutCache) -> Vec<PaintQuad> {
    let range = editor.selection.range();
    if range.start == range.end || layout.paras.is_empty() {
        return Vec::new();
    }
    let lh = layout.line_height;
    let mut quads = Vec::new();
    let last_para = range.end.para.min(layout.paras.len() - 1);
    for para_ix in range.start.para..=last_para {
        let p = &layout.paras[para_ix];
        let len = p.line.len();
        let sel_start = if para_ix == range.start.para { range.start.offset } else { 0 };
        let sel_end = if para_ix == range.end.para { range.end.offset.min(len) } else { len };
        let continues = para_ix < range.end.para;
        for k in 0..p.line_count() {
            let (line_start, line_end) = p.line_range(k);
            let last_line = k + 1 == p.line_count();
            let s = sel_start.max(line_start);
            let e = sel_end.min(line_end);
            let newline_marker = continues && last_line && e == len;
            if s > e || (s == e && !newline_marker) {
                continue;
            }
            let x0 = p.x_in_line(k, s);
            let mut x1 = p.x_in_line(k, e);
            if newline_marker {
                x1 += px(editor.config.editor.font_size * 0.4);
            } else if e == line_end && !last_line {
                x1 = layout.width;
            }
            let top = layout.origin.y + p.top + lh * k as f32;
            quads.push(fill(
                Bounds::from_corners(
                    point(layout.origin.x + x0, top),
                    point(layout.origin.x + x1, top + lh),
                ),
                theme::selection(),
            ));
        }
    }
    quads
}

/// Adjust `scroll` so the caret is visible. Returns true if the offset changed.
fn scroll_into_view(scroll: &ScrollHandle, caret: Point<Pixels>, line_height: Pixels) -> bool {
    let viewport = scroll.bounds();
    if viewport.size.height <= px(0.) {
        return false;
    }
    let top = viewport.origin.y + line_height;
    let bottom = viewport.origin.y + viewport.size.height - line_height;
    let mut offset = scroll.offset();
    if caret.y < top {
        offset.y += top - caret.y;
    } else if caret.y + line_height > bottom {
        offset.y -= caret.y + line_height - bottom;
    } else {
        return false;
    }
    offset.y = clamp_px(offset.y, -scroll.max_offset().height, px(0.));
    scroll.set_offset(offset);
    true
}

        _inspector_id: Option<&InspectorElementId>,
        bounds: Bounds<Pixels>,
        _request_layout: &mut Self::RequestLayoutState,
        window: &mut Window,
        cx: &mut App,
    ) -> Self::PrepaintState {
        let editor = self.editor.read(cx);
        let layout = build_layout(editor, bounds.size.width, bounds.origin, window);
        let lh = layout.line_height;
        let selection = selection_quads(editor, &layout);
        let block = editor.vim_captures_text();
        let cursor = layout.window_point(editor.selection.head).map(|caret| {
            let width = if block { px(editor.config.editor.font_size * 0.55) } else { px(2.) };
            let mut color = theme::cursor();
            if block {
                color.a = 0.45;
            }
            fill(Bounds::new(caret, size(width, lh)), color)
        });
        let wants_autoscroll = editor.autoscroll;
        let caret = layout.window_point(editor.selection.head);
        let scroll = editor.scroll.clone();
        if wants_autoscroll {
            if let Some(caret) = caret {
                if scroll_into_view(&scroll, caret, lh) {
                    window.request_animation_frame();
                }
            }
            self.editor.update(cx, |editor, _| editor.autoscroll = false);
        }
        Some(EditorPrepaint { layout, selection, cursor })
    }

    fn paint(
        &mut self,
        _id: Option<&GlobalElementId>,
        _inspector_id: Option<&InspectorElementId>,
        bounds: Bounds<Pixels>,
        _request_layout: &mut Self::RequestLayoutState,
        prepaint: &mut Self::PrepaintState,
        window: &mut Window,
        cx: &mut App,
    ) {
        let Some(prepaint) = prepaint.take() else { return };
        let focus_handle = self.editor.read(cx).focus_handle.clone();
        window.handle_input(&focus_handle, ElementInputHandler::new(bounds, self.editor.clone()), cx);
        for quad in prepaint.selection {
            window.paint_quad(quad);
        }
        let lh = prepaint.layout.line_height;
        for para in &prepaint.layout.paras {
            let origin = point(bounds.origin.x, bounds.origin.y + para.top);
            para.line.paint(origin, lh, TextAlign::Left, None, window, cx).ok();
        }
        if focus_handle.is_focused(window) {
            if let Some(cursor) = prepaint.cursor {
                window.paint_quad(cursor);
            }
        }
        let layout = prepaint.layout;
        self.editor.update(cx, |editor, _| editor.layout = Some(layout));
    }
}

                e.load(Document::new(), cx);
                e.set_notice("New file", cx);

/// How positions move when alternate editing ends and an emptied option is replaced by the
/// previous one (only positions at or after the group's start, in its paragraph, move).
#[derive(Clone, Copy, Debug, Default)]
pub(crate) struct Shift {
    para: usize,
    start: usize,
    delta: usize,
}

impl Shift {
    pub(crate) fn apply(self, pos: DocPos) -> DocPos {
        if self.delta > 0 && pos.para == self.para && pos.offset >= self.start {
            DocPos::new(pos.para, pos.offset + self.delta)
        } else {
            pos
        }
    }
}

impl Editor {
    /// Record an undo step (call before mutating) and drop trim suggestions in the touched
    /// paragraphs (`touched` is a range of paragraph indices).
    pub(crate) fn begin_edit(&mut self, kind: EditKind, touched: Range<usize>) {
        let (doc, selection) = (&self.doc, self.selection);
        self.history.record(kind, Instant::now(), || (doc.clone(), selection));
        let end = touched.end.min(self.doc.paragraphs.len());
        let ids: Vec<ParaId> = self
            .doc
            .paragraphs
            .get(touched.start.min(end)..end)
            .map(|ps| ps.iter().map(|p| p.id).collect())
            .unwrap_or_default();
        self.trims.retain(|t| !ids.contains(&t.para_id));
    }

    pub(crate) fn end_edit(&mut self, cx: &mut Context<Self>) {
        self.selection = Selection {
            anchor: self.doc.clamp(self.selection.anchor),
            head: self.doc.clamp(self.selection.head),
        };
        self.dirty = true;
        self.autoscroll = true;
        self.goal_x = None;
        self.notice = None;
        cx.notify();
    }

    /// Move the selection. Ends alternate editing when the selection leaves the edited group.
    pub(crate) fn set_selection(&mut self, selection: Selection, cx: &mut Context<Self>) {
        self.selection =
            Selection { anchor: self.doc.clamp(selection.anchor), head: self.doc.clamp(selection.head) };
        if self.alt_edit.is_some() && self.alt_edit_target(self.selection.range()).is_none() {
            self.finish_alt_edit();
        }
        self.marked = None;
        self.history.break_coalescing();
        self.autoscroll = true;
        cx.notify();
    }

    /// End alternate editing. Also shifts the selection; returns the shift for other positions.
    pub(crate) fn finish_alt_edit(&mut self) -> Shift {
        let Some(edit) = self.alt_edit.take() else { return Shift::default() };
        let Some(para) = self.doc.para_index(edit.para_id) else { return Shift::default() };
        let Some(seg) = self.doc.paragraphs[para].alt_starting_at(edit.start) else {
            return Shift::default();
        };
        let before = self.doc.paragraphs[para].len();
        self.doc.finish_alt_edit(para, seg);
        let after = self.doc.paragraphs[para].len();
        if after != before {
            self.dirty = true;
        }
        let shift = Shift { para, start: edit.start, delta: after.saturating_sub(before) };
        self.selection =
            Selection { anchor: shift.apply(self.selection.anchor), head: shift.apply(self.selection.head) };
        shift
    }

    /// If `range` lies within the edited group (edges included), its paragraph, segment and
    /// range local to the group's active text.
    pub(crate) fn alt_edit_target(&self, range: Range<DocPos>) -> Option<(usize, usize, Range<usize>)> {
        let edit = self.alt_edit?;
        let para = self.doc.para_index(edit.para_id)?;
        if range.start.para != para || range.end.para != para {
            return None;
        }
        let p = &self.doc.paragraphs[para];
        let seg = p.alt_starting_at(edit.start)?;
        let span = p.segment_ranges()[seg].clone();
        (span.start <= range.start.offset && range.end.offset <= span.end)
            .then(|| (para, seg, range.start.offset - span.start..range.end.offset - span.start))
    }

    /// After typing strictly inside an alternate, keep editing that group.
    fn enter_alt_edit_if_inside(&mut self, pos: DocPos) {
        let p = &self.doc.paragraphs[pos.para];
        if let Some(seg) = p.alt_at(pos.offset) {
            let span = p.segment_ranges()[seg].clone();
            if span.start < pos.offset {
                self.alt_edit = Some(AltEdit { para_id: p.id, start: span.start });
            }
        }
    }

    /// Replace the selection with `text` (newlines split paragraphs).
    pub fn insert_text(&mut self, text: &str, cx: &mut Context<Self>) {
        let range = self.selection.range();
        let kind = if text.chars().count() == 1 && text != "\n" && range.start == range.end {
            EditKind::Typing { para: range.start.para }
        } else {
            EditKind::Other
        };
        if !text.contains('\n') {
            if let Some((para, seg, local)) = self.alt_edit_target(range.clone()) {
                self.begin_edit(kind, para..para + 1);
                let start = self.doc.paragraphs[para].segment_ranges()[seg].start;
                self.doc.edit_alt(para, seg, local.clone(), text);
                self.selection = Selection::caret(DocPos::new(para, start + local.start + text.len()));
                self.end_edit(cx);
                return;
            }
        }
        let shift = self.finish_alt_edit();
        let range = shift.apply(range.start)..shift.apply(range.end);
        self.begin_edit(kind, range.start.para..range.end.para + 1);
        let start = self.doc.delete(range);
        let end = self.doc.insert(start, text);
        self.selection = Selection::caret(end);
        if !text.is_empty() {
            self.enter_alt_edit_if_inside(end);
        }
        self.end_edit(cx);
    }

    pub(crate) fn delete_range(&mut self, range: Range<DocPos>, kind: EditKind, cx: &mut Context<Self>) {
        if range.start >= range.end {
            return;
        }
        if let Some((para, seg, local)) = self.alt_edit_target(range.clone()) {
            self.begin_edit(kind, para..para + 1);
            self.doc.edit_alt(para, seg, local, "");
            self.selection = Selection::caret(range.start);
            self.end_edit(cx);
            return;
        }
        let shift = self.finish_alt_edit();
        let range = shift.apply(range.start)..shift.apply(range.end);
        self.begin_edit(kind, range.start.para..range.end.para + 1);
        let start = self.doc.delete(range);
        self.selection = Selection::caret(start);
        self.end_edit(cx);
    }

    pub(crate) fn undo_steps(&mut self, count: usize, cx: &mut Context<Self>) {
        for _ in 0..count.max(1) {
            let current = (self.doc.clone(), self.selection);
            let Some((doc, selection)) = self.history.undo(current) else { break };
            self.doc = doc;
            self.selection = selection;
        }
        self.after_history(cx);
    }

    pub(crate) fn redo_steps(&mut self, count: usize, cx: &mut Context<Self>) {
        for _ in 0..count.max(1) {
            let current = (self.doc.clone(), self.selection);
            let Some((doc, selection)) = self.history.redo(current) else { break };
            self.doc = doc;
            self.selection = selection;
        }
        self.after_history(cx);
    }

    fn after_history(&mut self, cx: &mut Context<Self>) {
        self.alt_edit = None;
        self.trims.clear();
        self.marked = None;
        self.goal_x = None;
        self.dirty = true;
        self.autoscroll = true;
        cx.notify();
    }
}

use std::ops::Range;

use gpui::{Bounds, Context, EntityInputHandler, Pixels, Point, UTF16Selection, Window, px, size};
use tulis_core::Selection;

use super::Editor;
use crate::utf16;

impl Editor {
    fn flat_range_of_selection(&self) -> Range<usize> {
        let r = self.selection.range();
        self.doc.flat_offset(r.start)..self.doc.flat_offset(r.end)
    }

    fn select_flat(&mut self, range: Range<usize>) {
        self.selection = Selection {
            anchor: self.doc.pos_from_flat(range.start),
            head: self.doc.pos_from_flat(range.end),
        };
    }
}

impl EntityInputHandler for Editor {
    fn text_for_range(
        &mut self,
        range_utf16: Range<usize>,
        actual_range: &mut Option<Range<usize>>,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<String> {
        let flat = self.doc.flat_text();
        let range = utf16::range_from_utf16(&flat, &range_utf16);
        actual_range.replace(utf16::range_to_utf16(&flat, &range));
        Some(flat[range].to_string())
    }

    fn selected_text_range(
        &mut self,
        _ignore_disabled_input: bool,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<UTF16Selection> {
        let flat = self.doc.flat_text();
        Some(UTF16Selection {
            range: utf16::range_to_utf16(&flat, &self.flat_range_of_selection()),
            reversed: self.selection.reversed(),
        })
    }

    fn marked_text_range(&self, _window: &mut Window, _cx: &mut Context<Self>) -> Option<Range<usize>> {
        let flat = self.doc.flat_text();
        self.marked.as_ref().map(|r| utf16::range_to_utf16(&flat, r))
    }

    fn unmark_text(&mut self, _window: &mut Window, _cx: &mut Context<Self>) {
        self.marked = None;
    }

    fn replace_text_in_range(
        &mut self,
        range_utf16: Option<Range<usize>>,
        text: &str,
        _window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let flat = self.doc.flat_text();
        if let Some(range) = range_utf16.map(|r| utf16::range_from_utf16(&flat, &r)).or(self.marked.clone()) {
            self.select_flat(range);
        }
        self.marked = None;
        self.insert_text(text, cx);
    }

    fn replace_and_mark_text_in_range(
        &mut self,
        range_utf16: Option<Range<usize>>,
        new_text: &str,
        new_selected_range_utf16: Option<Range<usize>>,
        _window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let flat = self.doc.flat_text();
        let range = range_utf16
            .map(|r| utf16::range_from_utf16(&flat, &r))
            .or(self.marked.clone())
            .unwrap_or_else(|| self.flat_range_of_selection());
        self.select_flat(range.clone());
        self.insert_text(new_text, cx);
        let start = range.start;
        self.marked = (!new_text.is_empty()).then(|| start..start + new_text.len());
        if let Some(sel) = new_selected_range_utf16 {
            let sel = utf16::range_from_utf16(new_text, &sel);
            self.select_flat(start + sel.start..start + sel.end);
        }
        cx.notify();
    }

    fn bounds_for_range(
        &mut self,
        range_utf16: Range<usize>,
        _element_bounds: Bounds<Pixels>,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<Bounds<Pixels>> {
        let flat = self.doc.flat_text();
        let range = utf16::range_from_utf16(&flat, &range_utf16);
        let layout = self.layout.as_ref()?;
        let origin = layout.window_point(self.doc.pos_from_flat(range.start))?;
        Some(Bounds::new(origin, size(px(2.), layout.line_height)))
    }

    fn character_index_for_point(
        &mut self,
        point: Point<Pixels>,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<usize> {
        let layout = self.layout.as_ref()?;
        let pos = self.doc.clamp(layout.pos_for_window_point(point));
        let flat = self.doc.flat_text();
        Some(utf16::offset_to_utf16(&flat, self.doc.flat_offset(pos)))
    }
}

use tulis_core::history::EditKind;
use tulis_core::motion as mv;

use super::Editor;

const PAGE_LINES: isize = 20;

impl Editor {
    /// The last frame's layout, if it still matches the document's paragraphs.
    pub(crate) fn current_layout(&self) -> Option<&LayoutCache> {
        self.layout.as_ref().filter(|l| l.paras.len() == self.doc.paragraphs.len())
    }

    fn extending(&self, shift_held: bool) -> bool {
        shift_held || self.vim.as_ref().is_some_and(|v| v.is_visual())
    }

    pub(crate) fn move_to(&mut self, pos: DocPos, extend: bool, cx: &mut Context<Self>) {
        let selection = if self.extending(extend) {
            Selection { anchor: self.selection.anchor, head: pos }
        } else {
            Selection::caret(pos)
        };
        self.goal_x = None;
        self.set_selection(selection, cx);
    }

    fn horizontal(&mut self, forward: bool, extend: bool, cx: &mut Context<Self>) {
        let sel = self.selection;
        let target = if !self.extending(extend) && !sel.is_empty() {
            if forward { sel.range().end } else { sel.range().start }
        } else if forward {
            mv::next_grapheme(&self.doc, sel.head)
        } else {
            mv::prev_grapheme(&self.doc, sel.head)
        };
        self.move_to(target, extend, cx);
    }

    pub(crate) fn vertical_move(&mut self, lines: isize, extend: bool, cx: &mut Context<Self>) {
        let head = self.selection.head;
        let Some(layout) = self.current_layout() else { return };
        let goal = self.goal_x.unwrap_or_else(|| layout.x_for(head));
        let target = layout.vertical(head, lines, goal);
        self.move_to(target, extend, cx);
        self.goal_x = Some(goal);
    }

    /// Start and end of the visual line at `pos` (the whole paragraph before the first layout).
    pub(crate) fn line_bounds(&self, pos: DocPos) -> (usize, usize) {
        let text = self.doc.paragraphs[pos.para].text();
        self.current_layout().map_or((0, text.len()), |layout| layout.line_bounds(pos, &text))
    }

        let head = self.selection.head;
        let (start, stop) = self.line_bounds(head);
        self.move_to(DocPos::new(head.para, if end { stop } else { start }), extend, cx);
    }

        let target = if forward {
            mv::next_word_start(&self.doc, head)

            mv::prev_word_start(&self.doc, head)

        self.move_to(target, extend, cx);

    pub(super) fn select_left(&mut self, _: &SelectLeft, _: &mut Window, cx: &mut Context<Self>) {

    pub(super) fn backspace(&mut self, _: &Backspace, _: &mut Window, cx: &mut Context<Self>) {
        let sel = self.selection;
        if !sel.is_empty() {
            self.delete_range(sel.range(), EditKind::Other, cx);
            return;
        }
        let start = mv::prev_grapheme(&self.doc, sel.head);
        let kind = if start.para == sel.head.para {
            EditKind::Typing { para: start.para }
        } else {
            EditKind::Other
        };
        self.delete_range(start..sel.head, kind, cx);
    }

    pub(super) fn delete(&mut self, _: &Delete, _: &mut Window, cx: &mut Context<Self>) {
        let sel = self.selection;
        if !sel.is_empty() {
            self.delete_range(sel.range(), EditKind::Other, cx);
            return;
        }
        let end = mv::next_grapheme(&self.doc, sel.head);
        let kind = if end.para == sel.head.para {
            EditKind::Typing { para: end.para }
        } else {
            EditKind::Other
        };
        self.delete_range(sel.head..end, kind, cx);
    }

    pub(super) fn copy(&mut self, _: &Copy, _: &mut Window, cx: &mut Context<Self>) {
        if !self.selection.is_empty() {
            let text = self.doc.text_in(self.selection.range());
            cx.write_to_clipboard(ClipboardItem::new_string(text));
        }
    }

    pub(super) fn cut(&mut self, _: &Cut, window: &mut Window, cx: &mut Context<Self>) {
        if !self.selection.is_empty() {
            self.copy(&Copy, window, cx);
            self.delete_range(self.selection.range(), EditKind::Other, cx);
        }
    }

    pub(super) fn paste(&mut self, _: &Paste, _: &mut Window, cx: &mut Context<Self>) {
        if let Some(text) = cx.read_from_clipboard().and_then(|item| item.text()) {
            self.insert_text(&text, cx);
        }
    }

    pub(super) fn undo(&mut self, _: &Undo, _: &mut Window, cx: &mut Context<Self>) {
        self.undo_steps(1, cx);
    }

    pub(super) fn redo(&mut self, _: &Redo, _: &mut Window, cx: &mut Context<Self>) {
        self.redo_steps(1, cx);
    }

    pub(super) fn on_mouse_down(&mut self, event: &MouseDownEvent, window: &mut Window, cx: &mut Context<Self>) {
        window.focus(&self.focus_handle);
        let Some(layout) = self.layout.as_ref() else { return };
        let pos = self.doc.clamp(layout.pos_for_window_point(event.position));
        self.is_selecting = true;
        match event.click_count {
            2 => {
                let text = self.doc.paragraphs[pos.para].text();
                let word = mv::word_range_at(&text, pos.offset);
                let selection = Selection {
                    anchor: DocPos::new(pos.para, word.start),
                    head: DocPos::new(pos.para, word.end),
                };
                self.set_selection(selection, cx);
            }
            n if n >= 3 => {
                let len = self.doc.paragraphs[pos.para].len();
                let selection =
                    Selection { anchor: DocPos::new(pos.para, 0), head: DocPos::new(pos.para, len) };
                self.set_selection(selection, cx);
            }
            _ => self.move_to(pos, event.modifiers.shift, cx),
        }
    }

    pub(super) fn on_mouse_move(&mut self, event: &MouseMoveEvent, _: &mut Window, cx: &mut Context<Self>) {
        if !self.is_selecting {
            return;
        }
        let Some(layout) = self.layout.as_ref() else { return };
        let pos = self.doc.clamp(layout.pos_for_window_point(event.position));
        self.move_to(pos, true, cx);
    }

    pub(super) fn on_mouse_up(&mut self, _: &MouseUpEvent, _: &mut Window, _: &mut Context<Self>) {
        self.is_selecting = false;
    }
}

//! Alternates, ghosting, overflow and trim-acceptance commands.

use std::ops::Range;
use std::time::Instant;

use gpui::{Context, Window};
use tulis_core::alternates::{AltLevel, OpError};
use tulis_core::history::EditKind;
use tulis_core::{DocPos, OverflowId, Selection};

use super::{AltEdit, Editor, TrimSuggestion};
use crate::actions::*;

impl Editor {
    /// The selection within one paragraph, or the cursor's whole paragraph when nothing is selected.
    pub(crate) fn target_range(&self) -> Result<(usize, Range<usize>), OpError> {
        let r = self.selection.range();
        if r.start.para != r.end.para {
            return Err(OpError::MultiParagraph);
        }
        if r.start == r.end {
            Ok((r.start.para, 0..self.doc.paragraphs[r.start.para].len()))
        } else {
            Ok((r.start.para, r.start.offset..r.end.offset))
        }
    }

    pub(super) fn make_alternate(&mut self, _: &MakeAlternate, _: &mut Window, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let sel = self.selection.range();
        if sel.start.para != sel.end.para {
            self.set_notice(OpError::MultiParagraph.to_string(), cx);
            return;
        }
        let para = sel.start.para;
        let p = &self.doc.paragraphs[para];
        // A selection makes (or extends) a word-level group; a bare cursor inside a group adds an
        // option to it; otherwise the whole paragraph gets a new version.
        let range = if sel.start != sel.end {
            Some(sel.start.offset..sel.end.offset)
        } else {
            p.alt_at(sel.start.offset).map(|i| p.segment_ranges()[i].clone())
        };
        let paragraph_empty = p.is_empty();
        match range {
            Some(range) => {
                self.begin_edit(EditKind::Other, para..para + 1);
                match self.doc.make_alt(para, range) {
                    Ok(span) => {
                        self.selection = Selection {
                            anchor: DocPos::new(para, span.start),
                            head: DocPos::new(para, span.end),
                        };
                        self.alt_edit =
                            Some(AltEdit { para_id: self.doc.paragraphs[para].id, start: span.start });
                        self.end_edit(cx);
                    }
                    Err(e) => self.set_notice(e.to_string(), cx),
                }
            }
            None if paragraph_empty => self.set_notice("Write something first", cx),
            None => {
                self.begin_edit(EditKind::Other, para..para + 1);
                self.doc.make_para_version(para);
                self.end_edit(cx);
            }
        }
    }

    pub(crate) fn cycle(&mut self, forward: bool, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let head = self.selection.head;
        if self.doc.alt_info(head).is_none() {
            self.set_notice("No alternates here", cx);
            return;
        }
        self.begin_edit(EditKind::Other, head.para..head.para + 1);
        if let Some(info) = self.doc.cycle(head, forward) {
            let offset = match info.level {
                AltLevel::Word => info.span.end,
                AltLevel::Paragraph => head.offset.min(info.span.end),
            };
            self.selection = Selection::caret(DocPos::new(head.para, offset));
        }
        self.end_edit(cx);
    }

    pub(super) fn cycle_next(&mut self, _: &CycleNext, _: &mut Window, cx: &mut Context<Self>) {
        self.cycle(true, cx);
    }

    pub(super) fn cycle_prev(&mut self, _: &CyclePrev, _: &mut Window, cx: &mut Context<Self>) {
        self.cycle(false, cx);
    }

    pub(super) fn accept_alternate(&mut self, _: &AcceptAlternate, _: &mut Window, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let head = self.selection.head;
        if self.doc.alt_info(head).is_none() {
            self.set_notice("No alternates here", cx);
            return;
        }
        self.begin_edit(EditKind::Other, head.para..head.para + 1);
        self.doc.accept(head);
        self.end_edit(cx);
    }

    pub(super) fn delete_alternate(&mut self, _: &DeleteAlternate, _: &mut Window, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let head = self.selection.head;
        if self.doc.alt_info(head).is_none() {
            self.set_notice("No alternates here", cx);
            return;
        }
        self.begin_edit(EditKind::Other, head.para..head.para + 1);
        if let Some(span) = self.doc.delete_option(head) {
            self.selection = Selection::caret(DocPos::new(head.para, span.end));
        }
        self.end_edit(cx);
    }

    pub(crate) fn toggle_ghost_here(&mut self, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let (para, range) = match self.target_range() {
            Ok(target) => target,
            Err(e) => return self.set_notice(e.to_string(), cx),
        };
        if range.is_empty() {
            return self.set_notice(OpError::EmptySelection.to_string(), cx);
        }
        self.begin_edit(EditKind::Other, para..para + 1);
        match self.doc.toggle_ghost(para, range) {
            Ok(_) => self.end_edit(cx),
            Err(e) => self.set_notice(e.to_string(), cx),
        }
    }

    pub(super) fn toggle_ghost(&mut self, _: &ToggleGhost, _: &mut Window, cx: &mut Context<Self>) {
        self.toggle_ghost_here(cx);
    }

    pub(super) fn send_to_overflow(&mut self, _: &SendToOverflow, _: &mut Window, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let sel = self.selection.range();
        let whole = sel.start == sel.end;
        let text = if whole {
            self.doc.paragraphs[sel.start.para].export_text()
        } else {
            self.doc.export_text_in(sel.clone())
        };
        if text.trim().is_empty() {
            return self.set_notice("Nothing to move to overflow", cx);
        }
        self.begin_edit(EditKind::Other, sel.start.para..sel.end.para + 1);
        let now = chrono::Utc::now();
        if whole {
            self.doc.paragraph_to_overflow(sel.start.para, now);
            let para = sel.start.para.min(self.doc.paragraphs.len() - 1);
            self.selection = Selection::caret(DocPos::new(para, 0));
        } else {
            self.doc.to_overflow(sel.clone(), now);
            self.selection = Selection::caret(sel.start);
        }
        self.end_edit(cx);
    }

    pub fn insert_overflow(&mut self, id: OverflowId, remove: bool, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let sel = self.selection.range();
        self.begin_edit(EditKind::Other, sel.start.para..sel.end.para + 1);
        let start = self.doc.delete(sel);
        if let Some(end) = self.doc.insert_overflow(id, start, remove) {
            self.selection = Selection::caret(end);
        }
        self.end_edit(cx);
    }

    pub fn remove_overflow(&mut self, id: OverflowId, cx: &mut Context<Self>) {
        self.begin_edit(EditKind::Other, 0..0);
        if self.doc.remove_overflow(id) {
            self.end_edit(cx);
        }
    }

    /// Accept the trim suggestion under the cursor (or the next one, or the first) by ghosting it.
    pub(super) fn accept_trim(&mut self, _: &AcceptTrim, _: &mut Window, cx: &mut Context<Self>) {
        if self.trims.is_empty() {
            return;
        }
        let head = self.selection.head;
        let head_id = self.doc.paragraphs[head.para].id;
        let order = |t: &TrimSuggestion| {
            (self.doc.para_index(t.para_id).unwrap_or(usize::MAX), t.range.start)
        };
        let under_cursor = self.trims.iter().position(|t| {
            t.para_id == head_id && t.range.start <= head.offset && head.offset <= t.range.end
        });
        let ix = under_cursor
            .or_else(|| {
                (0..self.trims.len())
                    .filter(|&i| order(&self.trims[i]) >= (head.para, head.offset))
                    .min_by_key(|&i| order(&self.trims[i]))
            })
            .or_else(|| (0..self.trims.len()).min_by_key(|&i| order(&self.trims[i])));
        let Some(ix) = ix else { return };
        let trim = self.trims.remove(ix);
        let Some(para) = self.doc.para_index(trim.para_id) else { return };
        // Not `begin_edit`: ghosting doesn't change rendered text, so the other suggestions stay valid.
        let (doc, selection) = (&self.doc, self.selection);
        self.history.record(EditKind::Other, Instant::now(), || (doc.clone(), selection));
        match self.doc.set_ghost(para, trim.range, true) {
            Ok(range) => {
                self.selection = Selection::caret(DocPos::new(para, range.end));
                self.dirty = true;
                self.autoscroll = true;
                cx.notify();
            }
            Err(e) => self.set_notice(e.to_string(), cx),
        }
    }

    /// Esc: cancel AI, else dismiss trims, else stop editing an alternate.
    pub(super) fn cancel(&mut self, _: &Cancel, _: &mut Window, cx: &mut Context<Self>) {
        if self.ai_task.take().is_some() {
            return self.set_notice("AI request cancelled", cx);
        }
        if !self.trims.is_empty() {
            self.trims.clear();
            return self.set_notice("Trim suggestions dismissed", cx);
        }
        self.finish_alt_edit();
        cx.notify();
    }
}

    /// Save to the current path. Returns false when there is no path yet or saving failed.
    pub(crate) fn save_now(&mut self, cx: &mut Context<Self>) -> bool {
        let Some(path) = self.path.clone() else { return false };
        let result = storage::save(&self.editor.read(cx).doc, &path);
        match result {
            Ok(()) => {

                    e.set_notice(format!("Saved {}", file_name(&path)), cx);

            }
        }

    fn save(&mut self, _: &Save, window: &mut Window, cx: &mut Context<Self>) {
        if self.path.is_none() {
            self.save_as(&SaveAs, window, cx);
        } else {
            self.save_now(cx);
        }

    fn save_as(&mut self, _: &SaveAs, window: &mut Window, cx: &mut Context<Self>) {
        let dir = self
            .path
            .as_ref()
            .and_then(|p| p.parent().map(Path::to_path_buf))

                ws.path = Some(path);
                ws.save_now(cx);
            })
            .ok();
        })
        .detach();

    fn open(&mut self, _: &Open, window: &mut Window, cx: &mut Context<Self>) {
        self.confirm_discard(window, cx, |_, window, cx| {
            let answer = cx.prompt_for_paths(PathPromptOptions {
                files: true,
                directories: false,
                multiple: false,
                prompt: None,
            });
            cx.spawn_in(window, async move |this, cx| {
                let Ok(Ok(Some(paths))) = answer.await else { return };

            ws.banner = None;
            ws.editor.update(cx, |e, cx| e.load(Document::new(), cx));

        self.confirm_discard(window, cx, |_, _, cx| cx.quit());

    fn request_close(&mut self, window: &mut Window, cx: &mut Context<Self>) -> bool {
        if !self.editor.read(cx).dirty {
            return true;
        }
        self.confirm_discard(window, cx, |_, window, _| window.remove_window());

    /// Run `then` now if there are no unsaved changes; otherwise ask Save / Don't Save / Cancel.
    /// Choosing Save on an untitled document opens Save As and does not continue.
    fn confirm_discard(
        &mut self,
        window: &mut Window,
        cx: &mut Context<Self>,
        then: impl FnOnce(&mut Self, &mut Window, &mut Context<Self>) + 'static,
    ) {
        if !self.editor.read(cx).dirty {
            then(self, window, cx);
            return;
        }
        let answer = window.prompt(
            PromptLevel::Warning,
            "Save changes to this document?",
            None,
            &["Save", "Don't Save", "Cancel"],
            cx,
        );
        cx.spawn_in(window, async move |this, cx| {
            let Ok(choice) = answer.await else { return };
            this.update_in(cx, |ws, window, cx| match choice {
                0 if ws.path.is_none() => ws.save_as(&SaveAs, window, cx),
                0 => {
                    if ws.save_now(cx) {
                        then(ws, window, cx);
                    }
                }
                1 => then(ws, window, cx),
                _ => {}
            })
            .ok();
        })
        .detach();
    }

//! AI alternates and AI trim: build requests, run them off the UI thread, apply results.

use std::ops::Range;
use std::sync::Arc;

use gpui::{Context, Window, prelude::*};
use tulis_core::ai::{AiError, CompletionRequest, LlmProvider, prompts, provider_from_config};
use tulis_core::history::EditKind;
use tulis_core::{AiKind, DocPos, ParaId, Selection, Source};

use super::{Editor, TrimSuggestion};
use crate::actions::{AiAlternates, AiTrimDocument, AiTrimParagraph};

pub(crate) const STALE_NOTICE: &str = "Text changed while AI was working; result dropped";

/// What an alternates request was about, so the result can be applied (or recognised as stale).
pub(crate) struct AlternatesJob {
    para_id: ParaId,
    range: Range<usize>,
    original: String,
    whole_paragraph: bool,
    source: Source,
}

impl Editor {
    fn provider(&mut self, cx: &mut Context<Self>) -> Option<Arc<dyn LlmProvider>> {
        if let Some(provider) = self.provider_override.clone() {
            return Some(provider);
        }
        match provider_from_config(&self.config.ai, |name| std::env::var(name).ok()) {
            Ok(provider) => Some(provider),
            Err(e) => {
                self.set_notice(e.to_string(), cx);
                None
            }
        }
    }

    pub(super) fn ai_alternates(&mut self, _: &AiAlternates, _: &mut Window, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let (para, range) = match self.target_range() {
            Ok(target) => target,
            Err(e) => return self.set_notice(e.to_string(), cx),
        };
        let whole_paragraph = self.selection.is_empty();
        let (original, export, para_id) = {
            let p = &self.doc.paragraphs[para];
            (p.text()[range.clone()].to_string(), p.export_text(), p.id)
        };
        if original.trim().is_empty() {
            return self.set_notice("Nothing to rewrite here", cx);
        }
        let count = self.config.ai.num_alternates.clamp(1, 8);
        let request = prompts::alternates_request(&export, &original, count);
        let Some(provider) = self.provider(cx) else { return };
        let source = Source::Ai {
            provider: provider.name().into(),
            model: provider.model().into(),
            kind: AiKind::Rewrite,
        };
        let job = AlternatesJob { para_id, range, original, whole_paragraph, source };
        let work = cx.background_spawn(async move { provider.complete(&request) });
        self.ai_task = Some(cx.spawn(async move |this, cx| {
            let result = work.await;
            this.update(cx, |editor, cx| {
                editor.ai_task = None;
                editor.apply_ai_alternates(job, result, cx);
            })
            .ok();
        }));
        self.set_notice("AI is writing alternatives…", cx);
    }

    pub(crate) fn apply_ai_alternates(
        &mut self,
        job: AlternatesJob,
        result: Result<String, AiError>,
        cx: &mut Context<Self>,
    ) {
        let response = match result {
            Ok(response) => response,
            Err(e) => return self.set_notice(e.to_string(), cx),
        };
        let texts = prompts::parse_alternates(&response, &job.original);
        if texts.is_empty() {
            return self.set_notice("AI returned no alternatives", cx);
        }
        self.finish_alt_edit();
        let Some(para) = self.doc.para_index(job.para_id) else {
            return self.set_notice(STALE_NOTICE, cx);
        };
        if self.doc.paragraphs[para].text().get(job.range.clone()) != Some(job.original.as_str()) {
            return self.set_notice(STALE_NOTICE, cx);
        }
        let count = texts.len();
        self.begin_edit(EditKind::Other, para..para + 1);
        if job.whole_paragraph {
            if let Err(e) = self.doc.add_ai_versions(para, texts, job.source) {
                return self.set_notice(e.to_string(), cx);
            }
            self.selection = Selection::caret(DocPos::new(para, 0));
        } else {
            match self.doc.add_ai_alternates(para, job.range, texts, job.source) {
                Ok(span) => self.selection = Selection::caret(DocPos::new(para, span.end)),
                Err(e) => return self.set_notice(e.to_string(), cx),
            }
        }
        self.end_edit(cx);
        self.set_notice(format!("{count} AI alternatives — Alt+↑/↓ to cycle"), cx);
    }

    pub(super) fn ai_trim_paragraph(&mut self, _: &AiTrimParagraph, _: &mut Window, cx: &mut Context<Self>) {
        let para = self.selection.head.para;
        self.start_trim(vec![para], cx);
    }

    pub(super) fn ai_trim_document(&mut self, _: &AiTrimDocument, _: &mut Window, cx: &mut Context<Self>) {
        let all = (0..self.doc.paragraphs.len()).collect();
        self.start_trim(all, cx);
    }

    fn start_trim(&mut self, paragraphs: Vec<usize>, cx: &mut Context<Self>) {
        self.finish_alt_edit();
        let jobs: Vec<(ParaId, String, CompletionRequest)> = paragraphs
            .into_iter()
            .filter_map(|i| {
                let p = &self.doc.paragraphs[i];
                let export = p.export_text();
                (!export.trim().is_empty()).then(|| (p.id, p.text(), prompts::trim_request(&export)))
            })
            .collect();
        if jobs.is_empty() {
            return self.set_notice("Nothing to trim", cx);
        }
        let Some(provider) = self.provider(cx) else { return };
        // One request per paragraph, in sequence, on the background executor.
        let work = cx.background_spawn(async move {
            jobs.into_iter()
                .map(|(id, text, request)| (id, text, provider.complete(&request)))
                .collect::<Vec<_>>()
        });
        self.ai_task = Some(cx.spawn(async move |this, cx| {
            let results = work.await;
            this.update(cx, |editor, cx| {
                editor.ai_task = None;
                editor.apply_trims(results, cx);
            })
            .ok();
        }));
        self.set_notice("AI is looking for cuts…", cx);
    }

    pub(crate) fn apply_trims(
        &mut self,
        results: Vec<(ParaId, String, Result<String, AiError>)>,
        cx: &mut Context<Self>,
    ) {
        let mut found = 0;
        let mut stale = 0;
        let mut error = None;
        for (id, text, result) in results {
            let response = match result {
                Ok(response) => response,
                Err(e) => {
                    error.get_or_insert(e.to_string());
                    continue;
                }
            };
            let Some(para) = self.doc.para_index(id) else {
                stale += 1;
                continue;
            };
            let p = &self.doc.paragraphs[para];
            if p.text() != text {
                stale += 1;
                continue;
            }
            let ranges = prompts::locate_trims(&prompts::parse_trim(&response), p);
            found += ranges.len();
            self.trims.retain(|t| t.para_id != id);
            self.trims.extend(ranges.into_iter().map(|range| TrimSuggestion { para_id: id, range }));
        }
        let mut notice = match (found, error) {
            (0, Some(e)) => e,
            (0, None) => "No cuts suggested".to_string(),
            (n, _) => format!("{n} suggested cuts — Tab to accept, Esc to dismiss"),
        };
        if stale > 0 {
            notice.push_str(&format!(" ({stale} changed paragraphs skipped)"));
        }
        self.set_notice(notice, cx);
    }
}

```rust
//! Executes vim commands against the editor.

use std::ops::Range;

use gpui::{Context, Window};
use tulis_core::history::EditKind;
use tulis_core::motion as mv;
use tulis_core::vim::{InsertAt, Mode, Motion, Operator, Vim, VimCommand, VimKey};
use tulis_core::{DocPos, Selection};

use super::Editor;
use crate::actions::ToggleVim;

impl Editor {
    pub(crate) fn vim_key(&mut self, key: VimKey, window: &mut Window, cx: &mut Context<Self>) {
        let Some(vim) = self.vim.as_mut() else { return };
        let commands = vim.feed(key);
        for command in commands {
            self.exec_vim(command, window, cx);
        }
        self.clamp_for_normal_mode();
        cx.notify();
    }

    pub(super) fn toggle_vim(&mut self, _: &ToggleVim, _: &mut Window, cx: &mut Context<Self>) {
        self.vim = if self.vim.is_some() { None } else { Some(Vim::new()) };
        self.clamp_for_normal_mode();
        let state = if self.vim.is_some() { "Vim mode on" } else { "Vim mode off" };
        self.set_notice(state, cx);
    }

    /// In Normal mode the cursor sits on a character, never past the end of a non-empty paragraph.
    fn clamp_for_normal_mode(&mut self) {
        if self.vim_mode() != Some(Mode::Normal) {
            return;
        }
        let head = self.selection.head;
        let len = self.doc.paragraphs[head.para].len();
        if len > 0 && head.offset >= len {
            let pos = mv::prev_grapheme(&self.doc, DocPos::new(head.para, len));
            self.selection = Selection::caret(pos);
        }
    }

    /// The next grapheme, but never across a paragraph boundary.
    fn next_in_para(&self, pos: DocPos) -> DocPos {
        let next = mv::next_grapheme(&self.doc, pos);
        if next.para == pos.para { next } else { pos }
    }

    fn motion_target(&self, from: DocPos, motion: Motion, count: usize) -> DocPos {
        let mut pos = from;
        for _ in 0..count.max(1) {
            pos = match motion {
                Motion::Left if pos.offset == 0 => pos,
                Motion::Left => mv::prev_grapheme(&self.doc, pos),
                Motion::Right => self.next_in_para(pos),
                Motion::Up | Motion::Down => {
                    let lines = if motion == Motion::Up { -1 } else { 1 };
                    match self.current_layout() {
                        Some(layout) => {
                            let goal = self.goal_x.unwrap_or_else(|| layout.x_for(from));
                            layout.vertical(pos, lines, goal)
                        }
                        None => pos,
                    }
                }
                Motion::WordForward => mv::next_word_start(&self.doc, pos),
                Motion::WordBackward => mv::prev_word_start(&self.doc, pos),
                Motion::WordEnd => mv::word_end(&self.doc, pos),
                Motion::LineStart => DocPos::new(pos.para, self.line_bounds(pos).0),
                Motion::FirstNonBlank => {
                    let (start, end) = self.line_bounds(pos);
                    let text = self.doc.paragraphs[pos.para].text();
                    let line = &text[start..end];
                    DocPos::new(pos.para, start + line.len() - line.trim_start().len())
                }
                Motion::LineEnd => DocPos::new(pos.para, self.line_bounds(pos).1),
                Motion::DocStart => DocPos::default(),
                Motion::DocEnd => DocPos::new(self.doc.paragraphs.len() - 1, 0),
                Motion::ParagraphForward => mv::next_paragraph(&self.doc, pos),
                Motion::ParagraphBackward => mv::prev_paragraph(&self.doc, pos),
            };
        }
        pos
    }

    /// Range and register text for whole paragraphs `first..=last`. For `change`, the (now empty)
    /// paragraph is kept to type into.
    fn paragraph_span(&self, first: usize, last: usize, change: bool) -> (Range<DocPos>, String) {
        let n = self.doc.paragraphs.len();
        let last = last.min(n - 1);
        let text = (first..=last).map(|i| self.doc.paragraphs[i].text()).collect::<Vec<_>>().join("\n");
        let last_len = self.doc.paragraphs[last].len();
        let range = if change {
            DocPos::new(first, 0)..DocPos::new(last, last_len)
        } else if last + 1 < n {
            DocPos::new(first, 0)..DocPos::new(last + 1, 0)
        } else if first > 0 {
            DocPos::new(first - 1, self.doc.paragraphs[first - 1].len())..DocPos::new(last, last_len)
        } else {
            DocPos::new(0, 0)..self.doc.end_pos()
        };
        (range, text)
    }

    fn apply_operator(
        &mut self,
        op: Operator,
        range: Range<DocPos>,
        register: String,
        linewise: bool,
        cx: &mut Context<Self>,
    ) {
        self.register = register;
        self.register_linewise = linewise;
        match op {
            Operator::Yank => self.set_selection(Selection::caret(range.start), cx),
            Operator::Delete | Operator::Change => self.delete_range(range, EditKind::Other, cx),
        }
    }

    fn exec_vim(&mut self, command: VimCommand, window: &mut Window, cx: &mut Context<Self>) {
        let head = self.selection.head;
        match command {
            VimCommand::Move { motion, count } => {
                let goal = self.goal_x;
                let target = self.motion_target(head, motion, count);
                self.move_to(target, false, cx);
                if matches!(motion, Motion::Up | Motion::Down) {
                    self.goal_x = goal.or_else(|| self.current_layout().map(|l| l.x_for(head)));
                }
            }
            VimCommand::Operate { op, motion, count } => {
                let motion = if op == Operator::Change && motion == Motion::WordForward {
                    Motion::WordEnd
                } else {
                    motion
                };
                let target = self.motion_target(head, motion, count);
                let range = if target < head {
                    target..head
                } else if motion == Motion::WordEnd {
                    head..self.next_in_para(target)
                } else {
                    head..target
                };
                let register = self.doc.text_in(range.clone());
                self.apply_operator(op, range, register, false, cx);
            }
            VimCommand::OperateParagraphs { op, count } => {
                let (range, text) =
                    self.paragraph_span(head.para, head.para + count.max(1) - 1, op == Operator::Change);
                self.apply_operator(op, range, text, true, cx);
            }
            VimCommand::OperateSelection { op, linewise } => {
                let selected = self.selection.range();
                let (range, text) = if linewise {
                    self.paragraph_span(selected.start.para, selected.end.para, op == Operator::Change)
                } else {
                    let range = selected.start..self.next_in_para(selected.end);
                    let text = self.doc.text_in(range.clone());
                    (range, text)
                };
                self.selection = Selection::caret(selected.start);
                self.apply_operator(op, range, text, linewise, cx);
            }
            VimCommand::DeleteChars { count } => {
                let mut end = head;
                for _ in 0..count.max(1) {
                    end = self.next_in_para(end);
                }
                if end > head {
                    let register = self.doc.text_in(head..end);
                    self.apply_operator(Operator::Delete, head..end, register, false, cx);
                }
            }
            VimCommand::Put { before, count } => self.vim_put(before, count, cx),
            VimCommand::EnterInsert(at) => self.vim_enter_insert(at, cx),
            VimCommand::BeginVisual => self.selection = Selection::caret(head),
            VimCommand::EndVisual => self.set_selection(Selection::caret(head), cx),
            VimCommand::ExitInsert => {
                self.finish_alt_edit();
                let head = self.selection.head;
                if head.offset > 0 {
                    let pos = mv::prev_grapheme(&self.doc, head);
                    self.set_selection(Selection::caret(pos), cx);
                }
            }
            VimCommand::Undo { count } => self.undo_steps(count, cx),
            VimCommand::Redo { count } => self.redo_steps(count, cx),
            VimCommand::CycleAlt { forward, count } => {
                for _ in 0..count.max(1) {
                    self.cycle(forward, cx);
                }
            }
            VimCommand::ToggleGhost => self.toggle_ghost_here(cx),
        }
        let _ = window;
    }

    fn vim_put(&mut self, before: bool, count: usize, cx: &mut Context<Self>) {
        if self.register.is_empty() {
            return;
        }
        let head = self.selection.head;
        let separator = if self.register_linewise { "\n" } else { "" };
        let text = vec![self.register.clone(); count.max(1)].join(separator);
        if self.register_linewise {
            let len = self.doc.paragraphs[head.para].len();
            let (pos, insert, target) = if before {
                (DocPos::new(head.para, 0), format!("{text}\n"), head.para)
            } else {
                (DocPos::new(head.para, len), format!("\n{text}"), head.para + 1)
            };
            self.selection = Selection::caret(pos);
            self.insert_text(&insert, cx);
            self.selection = Selection::caret(DocPos::new(target, 0));
        } else {
            let pos = if before { head } else { self.next_in_para(head) };
            self.selection = Selection::caret(pos);
            self.insert_text(&text, cx);
            let end = self.selection.head;
            self.selection = Selection::caret(mv::prev_grapheme(&self.doc, end));
        }
    }

    fn vim_enter_insert(&mut self, at: InsertAt, cx: &mut Context<Self>) {
        let head = self.selection.head;
        match at {
            InsertAt::Cursor => {}
            InsertAt::After => {
                let pos = self.next_in_para(head);
                self.move_to(pos, false, cx);
            }
            InsertAt::LineStart => {
                let pos = self.motion_target(head, Motion::FirstNonBlank, 1);
                self.move_to(pos, false, cx);
            }
            InsertAt::LineEnd => {
                let pos = self.motion_target(head, Motion::LineEnd, 1);
                self.move_to(pos, false, cx);
            }
            InsertAt::ParagraphBelow => {
                let len = self.doc.paragraphs[head.para].len();
                self.selection = Selection::caret(DocPos::new(head.para, len));
                self.insert_text("\n", cx);
            }
            InsertAt::ParagraphAbove => {
                self.selection = Selection::caret(DocPos::new(head.para, 0));
                self.insert_text("\n", cx);
                self.selection = Selection::caret(DocPos::new(head.para, 0));
            }
        }
    }
}

# Tulis

A writing app for playing with your words: keep alternates inline, ghost passages to judge a
paragraph without them, stash text in an overflow panel, and ask an AI for alternatives or cuts
(never rewrites). Built with Rust and [GPUI](https://www.gpui.rs/).

## Run

```

Files are plain Markdown (`essay.md`). Alternates, ghosts and overflow live in a sidecar next to it
(`essay.md.tulis.json`). If the Markdown is edited elsewhere, Tulis keeps the metadata of every
paragraph that still matches and tells you how many paragraphs lost theirs.

## Keys

`Ctrl` is `Cmd` on macOS.

| Key | Action |
|---|---|
| `Ctrl+D` | Make an alternate of the selection (then type the new wording), or a new version of the paragraph |
| `Alt+↑` / `Alt+↓` | Cycle alternates or paragraph versions |
| `Ctrl+Enter` | Accept: keep only the shown alternate/version |
| `Ctrl+Shift+Backspace` | Delete the shown alternate/version |
| `Ctrl+G` | Ghost / revive the selection or paragraph |
| `Ctrl+Shift+O` | Move the selection or paragraph to overflow |
| `Ctrl+\` | Show/hide the overflow panel |
| `Ctrl+J` | AI alternates for the selection or paragraph |
| `Ctrl+Shift+T` / `Ctrl+Shift+Alt+T` | AI trim suggestions for the paragraph / document; `Tab` accepts (ghosts), `Esc` dismisses |
| `Ctrl+Alt+V` | Toggle vim mode |
| `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+O` / `Ctrl+N` / `Ctrl+Q` | Save / Save as / Open / New / Quit |

Vim mode: `h j k l w b e 0 ^ $ gg G { }` with counts; `i a I A o O`; `d c y` + motion, `dd cc yy`,
